이 쪽에서는 조회 결과를 파일로 내보내는 방법과 파일의 데이터를 표에 넣는 방법을 설명합니다. 내보내기는 DB에 쓰지 않습니다. 가져오기는 표에 행을 넣고 커밋합니다.

## 결과 내보내기

결과 그리드의 내용을 파일로 저장합니다. 형식은 다섯 가지입니다.

| 형식 | 확장자 | 설명 |
|---|---|---|
| CSV | `.csv` | 쉼표로 나눈 글 파일입니다. UTF-8(BOM 있음)이고 줄 끝은 `CR LF`입니다. Excel에서 한글이 깨지지 않습니다. |
| TSV | `.tsv` | 탭으로 나눈 글 파일입니다. CSV와 같은 인코딩입니다. |
| Excel(xlsx) | `.xlsx` | Excel 통합 문서입니다. |
| JSON | `.json` | 행마다 객체 하나인 배열입니다. 열 이름이 겹치면 두 번째부터 `_2`, `_3`을 붙입니다. |
| INSERT 문(.sql) | `.sql` | 행마다 `INSERT INTO … VALUES (…);` 한 줄입니다. UTF-8(BOM 없음)입니다. |

### 내보내는 방법

1. SQL을 실행해 결과를 엽니다.
2. 내보내기 창을 엽니다. 방법은 둘 중 하나입니다.
   - **결과 > Excel 로 내보내기…**나 결과 그리드의 오른쪽 클릭 메뉴 「Excel 로 내보내기…」를 고릅니다. `Ctrl+Alt+E`(macOS `Cmd+Option+E`)도 같습니다. 창이 Excel 형식으로 열립니다.
   - 결과 그리드의 오른쪽 클릭 메뉴 「파일로 내보내기…」를 고릅니다. 창이 이번 실행에서 마지막에 쓴 형식으로 열립니다. 쓴 적이 없으면 CSV입니다.
3. 「형식」, 「범위」, 「저장 위치」를 확인합니다.
4. **내보내기**를 누릅니다.

결과가 없으면 창이 열리지 않고 「내보낼 결과가 없습니다.」가 나옵니다.

### 내보내기 창의 항목

| 항목 | 설명 |
|---|---|
| 형식 | CSV, TSV, Excel(xlsx), JSON, INSERT 문(.sql) 중에서 고릅니다. 형식을 바꾸면 저장 위치의 확장자도 바뀝니다. |
| 범위 | 무엇을 저장할지 고릅니다. 아래 표를 보세요. |
| 저장 위치 | 저장할 파일의 전체 경로입니다. **찾아보기…**로 폴더와 이름을 고릅니다. |
| 표 이름 | INSERT 형식일 때만 보입니다. INSERT 문에 쓸 표 이름입니다. 알 수 없으면 `TABLE_NAME`입니다. |
| 내보낸 뒤 열기 | 저장이 끝나면 운영체제의 기본 앱으로 파일을 엽니다. Excel 형식일 때 처음에 켜져 있습니다. |
| 고급 설정 | CSV, TSV, Excel 형식일 때 보입니다. 접혀 있습니다. 「첫 줄에 열 이름 넣기」(처음 값 켬)가 있습니다. Excel 형식에서는 「시트 이름」과 「시트당 최대 행」도 있습니다. |

범위는 다음 중에서 고릅니다. 상황에 맞는 항목만 보입니다.

| 범위 | 설명 |
|---|---|
| 전체 행(서버에서 다시 실행) | 질의를 서버에서 다시 실행해 처음부터 끝까지 저장합니다. 그리드에 불러온 행만이 아닙니다. 다시 실행할 문장을 알 수 없으면 고를 수 없습니다. |
| 그리드에 불러온 행 | 서버에 다시 묻지 않고 그리드의 값을 화면 순서대로 저장합니다. 정렬, 숨긴 열, 고친 값이 반영됩니다. |
| 보이는 행만 | 「결과 안에서 거르기」나 열 필터를 걸었을 때 「그리드에 불러온 행」 대신 이 이름으로 보입니다. 거르기가 적용된 행입니다. |
| 가져온 전체 | 거르기를 걸었을 때만 보입니다. 거르기를 무시하고 가져온 모든 행을 저장합니다. |
| 선택한 셀 | 선택한 셀의 행과 열만 저장합니다. 선택한 셀이 있을 때만 켜집니다. |

처음 고르는 범위는 다음과 같습니다. 거르기를 걸었으면 「보이는 행만」입니다. 거르기가 없고 다시 실행할 문장을 알면 「전체 행」입니다. 문장을 모르면 「그리드에 불러온 행」입니다.

### 저장 위치와 파일 이름

- 처음 값은 「폴더 + 이름 + 시각 + 확장자」입니다. 이름은 결과의 표 이름입니다. 표 이름을 모르면 「조회결과」입니다. 예: `조회결과_20261104_153000.csv`.
- 폴더는 이번 실행에서 마지막으로 내보낸 폴더입니다. 내보낸 적이 없으면 문서 폴더입니다. 앱을 다시 시작하면 문서 폴더로 돌아갑니다.
- 파일 이름에 못 쓰는 글자는 `_`로 바뀝니다.
- 경로가 잘못되면 창에 이유가 나옵니다.
  - 「저장할 파일 경로를 넣으세요.」
  - 「폴더부터 적은 전체 경로를 넣으세요.」
  - 「파일 이름에 쓸 수 없는 글자가 있습니다.」
  - 「폴더입니다. 끝에 파일 이름을 붙이세요.」
  - 「폴더가 없습니다: …」
- 같은 이름의 파일이 있으면 「같은 이름의 파일이 있습니다. 내보내면 덮어씁니다.」가 나옵니다. 이 경고는 막지 않습니다.

### 내보내는 동안

- 내보내는 동안 진행 줄이 돌고 「내보내는 중… N행」이 나옵니다. 이때 창의 항목은 바꿀 수 없습니다.
- **중단**을 누르면 멈추고 저장 중이던 파일을 지웁니다. 「내보내기를 취소했습니다. 저장 중이던 파일은 지웠습니다.」가 나옵니다.
- 끝나면 「N행을 내보냈습니다(n.n초): 경로」가 나옵니다.
- 실패하면 「내보내기에 실패했습니다: 이유」가 나옵니다.
- 「내보낸 뒤 열기」가 켜져 있는데 열지 못하면 「파일을 기본 앱으로 열지 못했습니다: 경로」가 나옵니다. 파일은 저장되어 있습니다.

### 알아 둘 것

- 「전체 행」은 질의를 서버에서 다시 실행하므로 SELECT를 한 번 더 실행합니다. 그동안 데이터가 바뀌었으면 화면과 다른 결과가 나올 수 있습니다.
- 질의에 바인드 변수가 있는데 값이 없거나 형식이 틀리면 서버를 부르기 전에 멈춥니다. 「바인드 변수 … 값이 없습니다 — 바인드 변수 창에서 값을 넣고 다시 실행하세요.」가 나옵니다.
- LOB 값은 미리보기 길이까지만 저장합니다. 이때 「열 …: LOB 값은 미리보기 길이까지만 내보냈다.」가 경고로 나옵니다. CLOB은 글자 그대로, BLOB은 16진수로 저장합니다.
- Excel 형식은 시트 하나에 최대 행 수가 있습니다. 처음 값은 1048575입니다. 넘으면 시트를 나눕니다. 시트 이름은 31자까지이고 `[ ] : * ? / \`는 `_`로 바뀝니다.
- 열 순서를 옮겼으면 서버에서 다시 읽는 내보내기도 그 순서를 따릅니다. 열 이름이 겹치거나 `FOR UPDATE`가 있으면 원래 순서로 저장합니다.

## 데이터 가져오기

CSV, TSV, xlsx 파일의 행을 DB의 표에 넣습니다. 파일 형식은 확장자로 정합니다. `.csv`, `.tsv`, `.txt`(탭으로 나눈 글), `.xlsx`를 읽습니다.

- 가져오기는 표에 행을 넣고 커밋합니다. 시작하기 전에 대상 접속이 맞는지 확인하세요.
- 읽기 전용 접속에서는 쓸 수 없습니다. 메뉴 항목이 꺼집니다.

### 가져오는 방법

1. **도구 > 데이터 가져오기(CSV·xlsx)**를 엽니다. SQL 탭이 활성이면 그 작업 공간의 세션을 씁니다.
2. 「파일」 칸에 파일 경로를 쓰거나 **찾아보기…**로 고릅니다.
3. 「대상 스키마」와 「표」에 대상 표를 씁니다. 이름은 대문자로 바뀌어 찾습니다.
4. **열 읽기**를 누릅니다. 파일의 앞부분과 표의 열 정보를 읽어 열 매핑을 만듭니다.
5. 열 매핑을 확인하고 필요하면 고칩니다.
6. **가져오기**를 누릅니다.

### 가져오기 창의 항목

| 항목 | 설명 |
|---|---|
| 파일(CSV·TSV·xlsx) | 가져올 파일의 경로입니다. |
| 대상 스키마, 표 | 행을 넣을 표입니다. |
| 열 읽기 | 파일과 표를 읽어 열 매핑과 미리보기를 만듭니다. 파일, 대상 스키마, 표가 모두 있어야 켜집니다. |
| 첫 줄은 열 이름 | 파일의 첫 줄을 열 이름으로 읽습니다. 처음 값은 켜짐입니다. 끄면 열 이름 대신 1, 2, 3 번호를 씁니다. |
| 배치 크기 | 한 번에 넣는 행 수입니다. 1에서 5000 사이입니다. 처음 값은 500입니다. |
| 끝에서 한 번에 커밋(끄면 배치마다 커밋) | 처음 값은 켜짐입니다. 아래 「커밋과 취소」를 보세요. |
| 열 매핑·타입 변환 미리보기 | 파일의 열마다 한 줄입니다. 왼쪽이 파일의 열 이름이고 가운데가 대상 열을 고르는 목록입니다. 오른쪽은 첫 데이터 행 기준의 변환 결과입니다. |
| 원본 앞부분 | 파일의 처음 몇 줄을 보입니다. 첫 줄과 데이터 5줄입니다. |
| 오류 행 | 넣지 못한 행의 목록입니다. 오류가 있을 때만 보입니다. |

### 열 매핑

- 파일의 열 이름과 같은 이름의 대상 열이 있으면 자동으로 골라집니다. 대소문자는 가리지 않습니다.
- 대상 열 목록에서 다른 열을 고르면 바뀝니다. 비워 두면 그 열은 건너뜁니다. 건너뛰면 미리보기에 「(건너뜀)」이 나옵니다.
- 가상 열은 목록에 없습니다.
- 미리보기는 `NUMBER → 123`처럼 대상 열의 자료형과 변환된 값을 보입니다. 변환하지 못하면 「오류 N건: 이유」가 빨간색으로 나옵니다. 이 열의 첫 5개 행을 검사한 결과입니다.
- 매핑한 열이 하나도 없으면 **가져오기**가 꺼집니다.
- 날짜는 `yyyy-MM-dd`, `yyyy-MM-dd HH:mm:ss`, `yyyy/MM/dd`, `yyyyMMdd` 같은 모양을 읽습니다.

### 가져오기 전에 확인하는 것

- 그 세션이 SQL을 실행하고 있으면 「그 세션은 지금 실행 중입니다. 실행이 끝난 뒤 가져오세요.」가 나오고 창이 열리지 않습니다.
- 그 세션에 커밋하지 않은 변경이 있으면 먼저 묻습니다. 가져오기의 커밋이 그 변경까지 확정하기 때문입니다. 커밋이나 롤백을 한 뒤에 가져오세요. 묻는 창에서 취소하면 가져오기를 시작하지 않습니다.

### 가져오는 동안과 끝난 뒤

- 가져오는 동안 진행 줄이 돌고 「가져오는 중…」이 나옵니다. **중단**으로 멈춥니다.
- 끝나면 「N행을 넣었다(n.n초).」가 나옵니다. 오류 행이 있으면 「오류 행 N건은 아래에 따로 적었다.」가 붙습니다. 끝에 「커밋했다.」나 「배치마다 커밋했다.」가 붙습니다.

### 오류 행

- 값을 변환하지 못한 행이나 DB가 거절한 행은 넣지 않고 「행 N: 이유」로 아래 목록에 적습니다. 행 번호는 파일의 행 번호입니다. 열 이름 줄도 한 행으로 셉니다.
- 오류 행이 있어도 나머지 행은 넣고 커밋합니다. 오류 행이 있으면 결과를 목록에서 꼭 확인하세요.
- 한 배치가 통째로 거절되면 그 배치를 한 행씩 다시 보내 틀린 행만 찾아냅니다.
- 목록에는 처음 1000건만 적습니다. 더 있으면 「오류 행이 더 있다(총 N건, 앞 1000건만 보고).」가 붙습니다.
- 모든 칸이 빈 줄은 건너뜁니다.

### 커밋과 취소

| 「끝에서 한 번에 커밋」 | 중간에 실패하거나 중단하면 |
|---|---|
| 켜짐(처음 값) | 이 가져오기가 넣은 행을 모두 되돌립니다. 가져오기 전에 있던 변경은 남습니다. 「취소했다. 아무것도 넣지 않았다(롤백).」가 나옵니다. |
| 꺼짐 | 배치마다 커밋하므로 이미 커밋한 배치는 남습니다. 「취소했다. 이미 커밋한 배치는 남아 있다.」가 나옵니다. |

- 행이 아주 많거나 되돌리기가 필요 없으면 「배치마다 커밋」이 부담이 적습니다. 되돌릴 수 있어야 하면 「끝에서 한 번에 커밋」을 쓰세요.
- 읽기 전용 접속은 INSERT가 막혀 아무것도 넣지 않습니다.
