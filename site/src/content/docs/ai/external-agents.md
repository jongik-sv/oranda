Oranda 밖에서 쓰는 LLM CLI(Claude Code, Codex, Antigravity의 `agy`, opencode)가 실행 중인 Oranda를 다룰 수 있습니다. CLI는 `orandactl` 명령으로 편집기 탭을 읽고, 바꿀 글을 제안하고, 새 탭에 SQL을 넣고, 접속의 객체를 찾고, SELECT를 실행합니다. 이 쪽에서는 연결을 켜는 창, CLI가 읽는 `oranda` 스킬, 상태 표시줄의 외부 에이전트 띠를 설명합니다.

- AI 튜닝 기능이 켜져 있어야 합니다. 꺼져 있으면 메뉴에 「외부 에이전트 연결…」이 보이지 않습니다. 기능은 **설정 > 기능**에서 켜고 끕니다. [설정](../../settings/options/#기능)을 보세요.
- 접속의 AI 허용 수준은 [AI 기능 개요](../overview/)를 보세요. 외부 에이전트도 같은 수준을 따릅니다.

## 외부 에이전트가 할 수 있는 일

| 일 | 설명 |
|---|---|
| 읽기 | 탭 목록, 탭의 글, 접속 목록, 객체·열·DDL, 결과 그리드에 이미 가져온 행, 마지막 오류를 읽습니다. |
| 제안 | 열려 있는 탭의 글을 바꾸려면 제안만 합니다. 사용자가 비교 창에서 받아들여야 들어갑니다. |
| 새 탭 | 새 탭을 열고 SQL을 넣습니다. 있는 글을 덮지 않습니다. |
| 실행 | SELECT 한 문장, 실행 계획, 통계만 실행합니다. INSERT·UPDATE·DELETE·DDL·PL/SQL은 탭에 넣기만 하고 사용자가 직접 실행합니다. |

- 운영 접속은 외부 에이전트에게 메타데이터만 줍니다. 탭의 글, 결과 행, 이력, 오류 글은 주지 않습니다.
- DB에서 온 글(주석, 소스, 오류, 행 값)은 에이전트에게 지시가 아니라 데이터로 전달됩니다.

## 외부 에이전트 연결 켜기

**도구 > 외부 에이전트 연결…**을 엽니다. 창마다 따로 켭니다. 켠 창만 CLI가 찾을 수 있습니다.

1. 「쓸 접속」에서 에이전트가 쓸 접속을 고릅니다. 개발 접속은 처음부터 골라져 있습니다. 시험 접속은 직접 고릅니다.
2. 운영 접속을 고르면 아래에 이름 칸이 생깁니다. 접속 이름을 그대로 다시 입력해야 「연결」이 눌립니다. 운영 접속은 「메타데이터만」으로 들어갑니다.
3. 필요하면 아래 확인란을 고릅니다.
4. 「연결」을 누릅니다. 위쪽에 「연결됨」과 붙은 CLI 이름, 끊기는 시각이 보입니다.

| 확인란 | 설명 |
|---|---|
| 조회 허용 | 고른 개발·시험 접속의 AI 허용 수준을 「조회 + 행 값」으로 올려 접속 설정에 저장합니다. 에이전트가 SELECT 결과의 행 값을 볼 수 있게 됩니다. 수준을 내리지는 않습니다. 내리려면 접속 편집의 「AI」 쪽에서 고칩니다. |
| 8시간 뒤 끊기 | 처음부터 골라져 있습니다. 끄면 앱을 끌 때까지 연결됩니다. |
| 접속 없는 탭의 글 읽기 허용 | 처음부터 골라져 있습니다. 접속을 고르지 않은 탭의 글을 에이전트가 읽을 수 있습니다. |

- 접속 목록의 수준은 그 접속에서 에이전트가 쓸 수 있는 가장 높은 수준입니다. AI 허용 수준이 「끔」인 접속은 고를 수 없습니다.
- 「연결」을 다시 누르면 옛 연결을 끊고 새로 연결합니다. 붙어 있던 CLI는 다시 붙어야 합니다.
- 「끊기」를 누르면 바로 끊습니다. 「연장」을 누르면 지금부터 다시 8시간 연결됩니다.
- 연결 정보(토큰)는 사용자 데이터 폴더의 `run/agents/` 아래 파일에만 씁니다. 같은 PC의 다른 사용자는 읽을 수 없습니다. 끊거나 앱을 끄면 지웁니다.

## CLI에서 쓰기

CLI는 스킬을 읽고 `orandactl` 을 부릅니다. 직접 불러 볼 수도 있습니다.

```text
orandactl status
orandactl tabs
orandactl tab get --tab <탭 id> --scope statement
orandactl query --conn <접속 별칭> - < new.sql
```

- 결과는 JSON 한 개입니다. `--text` 를 붙이면 사람이 읽는 글로 나옵니다.
- 상태 표시줄과 연결 창에는 부른 CLI 이름(Claude Code·Codex·opencode·Antigravity)이 보입니다. `orandactl` 이 CLI 가 셸에 넣는 표식으로 알아내므로 따로 줄 것은 없습니다. 다른 이름으로 보이게 하려면 환경 변수 `ORANDA_CLIENT` 를 정해 둡니다(명령 앞에 붙이면 Claude Code 의 실행 허락 규칙과 맞지 않으니 셸 설정에 둡니다).
- Oranda 창이 여럿 연결돼 있으면 `--instance <pid>` 로 고릅니다. `orandactl status --all` 이 창 목록을 보입니다.

### CLI 별 실행 허락

`orandactl` 은 이 PC 안의 통로로 Oranda 에 붙습니다. CLI 가 명령을 샌드박스에 가두면 붙지 못하므로 아래처럼 허락합니다. 스킬에도 같은 안내가 들어 있습니다.

| CLI | 허락 방법 |
|---|---|
| Claude Code | 처음 실행 때 묻는 창에서 허락합니다. 미리 허락하려면 `--allowedTools 'Bash("<orandactl 전체 경로>":*)'` 처럼 따옴표째 줍니다(경로에 공백이 있어도 맞습니다). |
| Codex | 읽기 전용·작업 폴더 쓰기 샌드박스에서는 통로가 막힙니다. `-c sandbox_workspace_write.network_access=true` 로 시작하거나 `orandactl` 을 샌드박스 밖에서 돌리도록 허락합니다. |
| Antigravity (`agy`) | 셸 명령을 먼저 샌드박스에서 돌립니다. `sandbox_blocked` 오류가 나면 같은 명령을 샌드박스 밖에서 다시 돌리도록 허락합니다. |

## oranda 스킬

LLM CLI는 스킬 파일(`SKILL.md`)을 읽고 `orandactl` 쓰는 법을 압니다. Oranda는 사용자 폴더 세 곳에 같은 스킬을 씁니다.

| 폴더 | 읽는 CLI |
|---|---|
| `~/.claude/skills/oranda/` | Claude Code, opencode |
| `~/.agents/skills/oranda/` | Codex, opencode |
| `~/.gemini/config/skills/oranda/` | Antigravity (`agy`) |

- 스킬에는 이 PC의 `orandactl` 전체 경로가 들어갑니다. PATH는 바꾸지 않습니다.
- Oranda가 쓴 스킬 파일은 머리말에 `# Oranda-managed: v1` 줄이 있습니다. 이 줄이 있는 파일만 Oranda가 다시 쓰거나 지웁니다. 스킬을 직접 고쳐 쓰려면 이 줄을 지우세요.
- 같은 자리에 이 줄이 없는 다른 `oranda` 스킬이 있으면 덮어쓰지 않습니다.
- Oranda가 띄우는 AI 튜닝·대화 실행은 이 스킬을 읽지 않습니다.

### 스킬 설치

연결 창의 「스킬 설치…」를 누릅니다.

1. 폴더마다 확인란, 읽는 CLI, 파일 경로, 지금 상태가 보입니다. 그 CLI의 설정 폴더가 있거나 이미 Oranda 스킬이 있는 줄은 처음부터 골라져 있습니다.
2. 「설치」를 누르면 고른 곳에 씁니다. 「지우기」를 누르면 고른 곳에서 Oranda가 쓴 스킬만 지웁니다.
3. 다른 `oranda` 스킬이 있어 건너뛴 줄에는 「덮어쓰기」가 생깁니다. 그 파일을 Oranda 스킬로 바꾸려면 누릅니다.

창 아래에 스킬이 부를 `orandactl` 경로와 결과가 보입니다.

macOS 에서 내려받은 앱을 응용 프로그램 폴더로 옮기지 않고 열면, 앱이 임시 위치(AppTranslocation)에서 실행됩니다. 이때는 스킬에 임시 경로가 적히므로 설치하지 않고 안내만 보입니다. 앱을 응용 프로그램 폴더로 옮겨 다시 연 뒤 설치합니다.

## 상태 표시줄의 외부 에이전트 띠

외부 에이전트가 연결되면 상태 표시줄에 띠가 생깁니다.

```text
에이전트 연결됨 · Claude Code · 최근 호출 12초 전 · 7시간 40분 남음  [끊기]
```

- 붙은 CLI 이름, 마지막 호출이 얼마 전인지, 연결이 끊길 때까지 남은 시간을 보입니다. 남은 시간이 없으면 앱을 끌 때까지 연결됩니다.
- 「끊기」를 누르면 바로 연결을 끊습니다. 에이전트의 다음 명령은 거부됩니다.
- 띠를 누르면 최근 호출 20개(시각, 도구, 판단, 돌려준 글 길이)가 보입니다. 판단은 「허용」·「가림」·「거부」·「실패」입니다.
- 끊길 때까지 10분이 남으면 목록 아래에 「연장」이 생깁니다. 누르면 지금부터 다시 8시간 연결됩니다.

### 스킬 다시 설치

Oranda를 다른 폴더에 다시 설치하거나 업데이트로 `orandactl` 위치가 바뀌면, 설치해 둔 스킬이 옛 경로를 가리킵니다. 이때 상태 표시줄에 「에이전트 스킬 다시 설치 필요」가 뜹니다. 띠를 누르고 「스킬 다시 설치」를 누르면 Oranda가 쓴 스킬만 새 경로로 다시 씁니다.
