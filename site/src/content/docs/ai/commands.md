AI 명령은 SQL 탭의 문장을 AI에게 맡기는 명령 다섯 개입니다. 이 쪽에서는 각 명령이 하는 일, 켜지는 조건, 결과를 받는 방법, 조인 문법 규칙을 설명합니다. 모델은 먼저 [AI 모델 설정](../models/)에서 골라야 하고, 접속마다 AI 허용 수준이 알맞아야 합니다. 허용 수준은 [AI 기능 개요](../overview/#접속의-ai-허용-수준)를 보세요.

## 명령 목록

| 명령 | 하는 일 | 문장을 실행하는가 |
|---|---|---|
| AI 튜닝 | 커서 위치 문장을 분석해 인덱스 후보와 재작성 제안을 받습니다. | 벤치마크를 켜면 SELECT를 실행합니다. |
| 이 문장 튜닝 | AI 튜닝과 같습니다. | AI 튜닝과 같습니다. |
| 실행 계획 해설 | 커서 위치 문장의 실행 계획을 풀어서 설명합니다. | 실행하지 않습니다. |
| SQL 설명 | 커서 위치 문장이 하는 일을 설명합니다. | 실행하지 않습니다. |
| 오류 고치기 | 마지막 실행 오류가 난 문장의 고친 문장을 제안합니다. | 고친 문장을 실행하지 않습니다. |

## 명령 실행하기

- 도구 모음의 「AI 튜닝」 단추를 누르면 AI 튜닝이 시작됩니다. 단추 옆 ▾ 목록에서 「이 문장 튜닝」, 「실행 계획 해설」, 「SQL 설명」, 「오류 고치기」를 고릅니다.
- **튜닝 > AI 튜닝**으로도 AI 튜닝을 시작합니다.
- 명령은 SQL 탭에 포커스가 있을 때 동작합니다.
- 명령을 실행하면 AI 대화 창이 열리고 결과가 쌓입니다. [AI 대화](../chat/)를 보세요.
- 명령 이름은 [명령 팔레트](../../settings/shortcuts/#명령-팔레트)에서도 찾을 수 있습니다. 범주는 「SQL」입니다.

### 켜지는 조건

모든 AI 명령은 다음 조건이 맞아야 켜집니다.

- 설정에서 AI 모델을 골랐습니다.
- 접속의 AI 허용 수준이 「끔」이 아닙니다.
- 접속이 있습니다.
- MyBatis 문서가 활성이 아닙니다.

명령마다 조건이 더 있습니다.

| 명령 | 더 필요한 조건 |
|---|---|
| 실행 계획 해설 | 접속의 AI 허용 수준이 「계획」 이상 |
| 오류 고치기 | 실행 오류가 있어야 합니다. |
| SQL 설명 | 없음 |
| AI 튜닝, 이 문장 튜닝 | 없음 |

## AI 튜닝과 이 문장 튜닝

두 명령은 같은 동작입니다. 실행하면 「AI 튜닝 시작」 창이 먼저 나옵니다. 시작 창의 항목은 [SQL 튜닝](../../plan/tuning/#ai-튜닝-시작-창)에서 설명합니다.

- 이미 진행 중인 AI 튜닝이 있으면 시작 창을 띄우지 않고 대화 창만 보입니다.
- 결과는 인덱스 후보와 재작성 제안입니다. 재작성 제안은 대화 창의 제안 카드에서 비교 창으로 확인한 뒤 새 탭에 넣습니다.
- 튜닝이 끝나면 결과를 레포트로 저장할 수 있습니다. [AI 대화](../chat/#튜닝-결과-레포트-저장)를 보세요.
- 기타 CLI가 선택되어 있으면 AI 튜닝은 시작되지 않습니다. 기타 CLI는 일반 대화, SQL 설명, 실행 계획 해설, 오류 고치기에 쓸 수 있습니다.

## 실행 계획 해설

커서 아래 문장의 실행 계획을 사람 말로 풀어 줍니다. 결과는 자유로운 글입니다.

- 계획 창에 이 문장의 계획이 떠 있으면(「실행하고 실제 계획」으로 연 계획 포함) 그 계획을 읽습니다.
- 계획 창의 계획이 이 문장의 것이 아니면 예상 계획을 읽습니다. 이때 접속의 「EXPLAIN PLAN 허용」이 켜져 있어야 합니다.
- 읽을 계획이 없으면 해설하지 않고 「읽을 수 있는 실행 계획이 없어 해설하지 않았습니다. …」를 안내합니다. 문장을 실행해 계획을 확인하거나 접속 편집에서 허용을 켠 뒤 다시 시도하세요.
- 화면의 계획 글은 AI에 보내지 않습니다. 대화 창에 「화면의 계획 글은 보내지 않고, AI 가 허용된 도구로 계획을 직접 읽습니다.」가 나옵니다. AI가 허용된 도구로 계획을 직접 읽으므로 접속의 허용 수준, 조건절 값 가림, 감사 기록을 거칩니다.
- 문장이 없으면 「해설할 SQL 문장이 없어 보내지 않았습니다. …」가 나옵니다. 편집기에서 문장 위에 커서를 놓고 다시 시도하세요.
- 벤치마크는 하지 않습니다. 문장을 다시 실행하지도 않습니다.
- 기타 CLI를 쓰면 앱이 같은 규칙으로 계획을 미리 읽어 글로 함께 보냅니다. 예상 계획이면 답의 첫 줄에 밝힙니다.

## SQL 설명

커서 아래 문장이 하는 일을 사람 말로 풀어 줍니다. 결과는 자유로운 글입니다.

- AI가 쓸 수 있는 도구는 객체 구조 조회뿐입니다. 필요한 표와 열의 구조만 읽습니다.
- 문장을 실행하지 않고 재작성이나 인덱스 제안도 하지 않습니다.
- 값을 가리는 대화에서는 주석 본문도 보내지 않습니다. 그래서 주석에 의존한 설명은 약할 수 있다고 대화 창에 안내합니다. 「로컬 AI」로 지정한 프로필로 보내면 주석 본문도 보냅니다.
- 문장이 없으면 「설명할 SQL 문장이 없어 보내지 않았습니다. …」가 나옵니다.
- 기타 CLI를 쓰면 문장 글만 보내고 DB의 값이나 객체 정보는 보내지 않습니다. 표와 열의 뜻은 이름으로 짐작한 설명일 수 있다고 안내합니다.

## 오류 고치기

마지막 실행 오류가 난 문장을 오류와 함께 AI에 보내 고친 문장을 받습니다.

1. SQL 탭에서 문장을 실행해 오류를 냅니다.
2. 같은 탭에서 도구 모음의 「AI 튜닝」 옆 ▾ 목록에서 **오류 고치기**를 고릅니다.
3. 대화 창에 원인을 굵은 한 줄로 쓰고, 고친 내용을 최대 3개 항목으로 쓰고, 적용하기 전에 확인할 것을 한 줄로 씁니다.
4. 제안 카드의 **적용**을 눌러 비교 창에서 확인하고 받아들입니다.

- 고친 문장은 실행하지 않습니다. 비교 창에서 받아들이면 원래 탭은 그대로 두고 「원래 탭 이름 (수정)」 새 탭에 넣습니다.
- AI는 객체 구조를 읽을 수 있고, 허용 수준이 「계획」 이상이면 고친 SELECT를 `EXPLAIN PLAN`으로 확인합니다. 벤치마크나 실행은 하지 않습니다.
- 값을 가리는 대화(운영 접속 포함)는 오류 문구의 본문을 보내지 않고 ORA 번호와 위치만 보냅니다. 대화 창에 그 사실이 안내됩니다. 「로컬 AI」로 지정한 프로필로 보내면 오류 문구의 본문도 보냅니다.
- 값을 가릴 수 없는 문장(닫히지 않은 문자열 등, 예: ORA-01756)은 가리는 접속에서 고칠 수 없습니다. 문장을 직접 고친 뒤 다시 시도하세요.
- 오류 앞에 한글 같은 멀티바이트 글자가 있으면 오류 위치가 실제보다 뒤로 표시될 수 있습니다.
- 기타 CLI를 쓰면 앱이 허용된 도구로 읽은 객체 정보를 함께 보냅니다. 읽지 못하면 그 사실을 적어 보냅니다.

오류 고치기가 보내지 않고 안내만 하는 경우는 다음과 같습니다.

| 안내 | 원인 |
|---|---|
| 고칠 실행 오류가 없습니다. 오류가 난 문장을 먼저 실행하세요. | 오류 기록이 없거나 성공한 실행이 지웠습니다. |
| 마지막 오류가 난 접속을 확인할 수 없어 보내지 않았습니다. | 오류가 난 접속이나 지금 접속을 알 수 없습니다. |
| 마지막 오류는 지금 접속이 아닌 다른 접속에서 난 것이라 보내지 않았습니다. | 접속을 바꾼 뒤입니다. 그 접속으로 돌아가 문장을 다시 실행하세요. |
| 마지막 오류가 SQL 탭이 아니라 PL/SQL 실행 창에서 난 것이라 고치지 않습니다. | PL/SQL 실행 창의 오류는 고치지 않습니다. SQL 탭에서 실행한 문장의 오류만 고칩니다. |
| 마지막 오류는 지금 탭이 아닌 다른 탭에서 난 것이라 보내지 않았습니다. | 오류가 난 탭을 열고 다시 시도하세요. |
| 오류가 난 탭이 닫혀 보내지 않았습니다. | 탭이 닫혔습니다. |
| 오류가 난 뒤 문장이 바뀌어 보내지 않았습니다. | 문장을 다시 실행해 오류를 확인한 뒤 시도하세요. |

## 조인 문법

설정 > AI 모델의 「AI 가 쓰는 조인 문법」에서 Oracle(기본)이나 ANSI를 고릅니다. 이 설정은 AI 튜닝의 재작성 제안과 오류 고치기에 적용됩니다. 규칙은 [AI 모델 설정](../models/#조인-문법)을 보세요. 이 규칙은 AI에 주는 지시이며 Oranda가 결과를 검사하거나 바꾸지는 않으므로, 적용하기 전에 비교 창에서 확인하세요.

## 확인 창

AI 설정 화면에는 되돌릴 수 없는 일을 하기 전에 나오는 작은 확인 창이 있습니다. 프로필 삭제, 저장하지 않은 변경 버림, 기타 CLI 삭제가 그렇습니다. 창에는 질문 글과 「확인」, 「취소」 단추가 있고 `Enter`는 확인, `Esc`는 취소입니다. [AI 모델 설정](../models/#삭제와-확인-창)을 보세요.

## 문제가 생길 때

| 증상 | 원인 | 해결 |
|---|---|---|
| AI 명령이 모두 회색입니다 | 모델을 「선택 안 함」으로 두었거나, 접속의 AI 허용 수준이 「끔」이거나, 접속이 없거나, MyBatis 문서가 활성입니다. | **설정 > AI 모델**과 접속 편집의 「AI 허용 수준」을 확인하세요. |
| 「AI 튜닝」 단추와 ▾ 목록이 보이지 않습니다 | AI 튜닝 기능이 꺼져 있습니다. | **설정 > 기능**에서 기능을 확인하세요. |
| 「실행 계획 해설」만 회색입니다 | 접속의 AI 허용 수준이 「계획」 미만입니다. | 접속 편집에서 수준을 「계획」 이상으로 올리세요. |
| 「오류 고치기」만 회색입니다 | 고칠 실행 오류가 없습니다. | 오류가 난 문장을 먼저 실행하세요. |
| 「읽을 수 있는 실행 계획이 없어 해설하지 않았습니다」가 나옵니다 | 계획 창의 계획이 이 문장의 것이 아니고 EXPLAIN PLAN 허용이 꺼져 있습니다. | 문장을 실행해 계획을 확인하거나 접속 편집에서 EXPLAIN PLAN 허용을 켜세요. |
| 가린 접속에서 오류 고치기가 거부됩니다 | 문장의 값을 가릴 수 없습니다. | 문장을 직접 고친 뒤 다시 시도하세요. |
| 기타 CLI를 골랐는데 AI 튜닝이 시작되지 않습니다 | 기타 CLI는 튜닝에 쓸 수 없습니다. | 다른 모델을 고르세요. |
| 운영 접속에서 기타 CLI로 보내지 않습니다 | 기타 CLI는 운영 접속과 값 가림 접속에 보내지 않습니다. | 다른 모델을 고르세요. |
