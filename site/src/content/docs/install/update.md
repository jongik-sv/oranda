설치 파일로 설치한 Oranda는 새 버전을 확인하고 내려받아 적용합니다. 개발 빌드처럼 설치하지 않은 실행본은 자동 업데이트를 쓸 수 없습니다.

## 자동 확인

- 메인 창이 뜨고 5초 뒤에 한 번 확인합니다.
- 앱이 떠 있는 동안에는 1시간마다 확인합니다.
- 확인은 조용히 진행합니다. 새 버전이 없으면 아무것도 표시하지 않습니다.
- 새 버전을 찾으면 상태 표시줄에 「업데이트 … 있음」이 나타납니다. 상태 표시줄 항목을 누르면 업데이트 창이 열립니다.

## 직접 확인

1. 도움말 메뉴에서 **업데이트 확인…**을 엽니다.
2. 업데이트 창이 현재 버전과 확인 결과를 표시합니다. 결과는 「최신 버전입니다」 또는 「새 버전이 나왔습니다: …」입니다.
3. 결과가 오래되었으면 **다시 확인**을 누릅니다.

## 새 버전 적용

1. **다운로드**를 누릅니다. 설정에서 「새 버전을 자동으로 받기」를 켜 두었으면 이 단계를 건너뜁니다. 진행률은 업데이트 창과 상태 표시줄에 표시됩니다.
2. 내려받기가 끝나면 적용 방법을 고릅니다.
   - **종료할 때 적용**: 앱을 끝낼 때 새 버전이 적용됩니다.
   - **지금 다시 시작해 적용**: 저장하지 않은 탭이나 커밋하지 않은 트랜잭션이 있으면 먼저 묻습니다. 확인이 끝나면 앱이 다시 시작합니다.

그 밖의 단추는 다음과 같습니다.

- **이 버전 건너뛰기**: 찾은 버전을 건너뜁니다. 건너뛴 버전은 설정에서 지울 수 있습니다.
- **다운로드 취소**: 내려받는 중일 때 나타납니다.
- **설정 열기**: 업데이트 서버가 설정되지 않았거나 주소가 올바르지 않을 때만 나타납니다. 업데이트 창을 닫고 설정 창을 엽니다.

## 업데이트 설정

설정 창의 **업데이트** 탭에서 아래 항목을 바꿉니다.

| 항목 | 설명 |
|---|---|
| 현재 버전 | 설치된 버전을 표시합니다. |
| 시작할 때와 실행 중에 업데이트 확인 | 끄면 자동 확인을 하지 않습니다. 직접 확인은 계속 쓸 수 있습니다. |
| 새 버전을 자동으로 받기 | 켜면 찾은 새 버전을 바로 내려받습니다. |
| 업데이트 서버 주소 | 비워 두면 기본 주소를 씁니다. GitHub 저장소 주소, 릴리스 주소, 폴더 경로를 넣을 수 있습니다. |
| 마지막 확인 | 마지막으로 확인한 시각을 표시합니다. |
| 건너뛴 버전 | 건너뛴 버전을 표시하고 **건너뛴 버전 지우기**로 지웁니다. |
| 지금 확인 | 저장한 설정으로 바로 확인합니다. |

업데이트 서버 주소는 `http` 또는 `https` 주소나 절대 경로 폴더만 쓸 수 있습니다. 암호화하지 않은 `http` 주소를 넣으면 경고가 나타납니다. 신뢰하는 내부망에서만 쓰세요.

조직 내부 서버로 업데이트를 받으려면 업데이트 서버 주소에 내부 서버의 주소를 넣습니다.

## 릴리스 노트

도움말 메뉴의 **새 기능(릴리스 노트)**을 열면 앱에 포함된 릴리스 노트 창이 열립니다. 이 창은 인터넷 없이도 열립니다. 창이 이미 열려 있으면 앞으로 가져옵니다. 이전 버전의 전체 목록은 창의 링크로 GitHub Releases에서 봅니다.

## 확인에 실패할 때

| 메시지 | 확인할 것 |
|---|---|
| 업데이트 서버에 닿지 않습니다 | 네트워크, 프록시, 방화벽을 확인합니다. |
| 업데이트 파일을 찾지 못했습니다 | 업데이트 서버 주소를 확인합니다. |
| 요청 한도를 넘었거나 서버가 요청을 거절했습니다 | 잠시 뒤 다시 확인합니다. |
| 업데이트 서버 주소가 올바르지 않습니다 | 설정의 주소 형식을 고칩니다. |
