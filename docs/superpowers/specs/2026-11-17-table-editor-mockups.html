테이블 편집기 — 어디서 고칠까?

둘 다 「바뀐 칸 노란색 · 새 열 초록 · 지울 열 빨강」, 아래에 ALTER 문이 바로 보이고, 실행 · 묶음에 넣기 · 스크립트 저장이 있습니다. 다른 건 편집하는 장소입니다.

A

객체 상세에서 바로 편집 (결과 그리드 편집 모드처럼)

B

스키마 브라우저 「테이블 편집…」 · 「새 테이블…」, 객체 상세의 「편집」 단추로 문서 탭을 엽니다. 새 테이블과 고치기가 같은 화면.

A안 이어서 — 새 테이블 · 반영 묶음

둘 다 제 제안입니다. 틀린 곳·빠진 곳을 터미널로 알려 주세요.

① 새 테이블: 빈 객체 상세 탭이 편집 모드로 열림

스키마 브라우저에서 소유자나 「테이블」 노드 오른쪽 클릭 → 「새 테이블…」. 열·제약·인덱스 페이지만 켜지고(통계·크기 등은 흐림), 처음부터 편집 모드입니다. 실행하면 같은 탭이 진짜 테이블 상세로 바뀝니다.

② 반영 묶음 창: 아래 도구 창(변경 일지 옆)

「묶음에 넣기 ▾」는 지금 묶음에 넣거나 새 묶음을 만듭니다. SQL 편집기에서 DDL을 실행하면 「지금 묶음」이 있을 때 자동으로 쌓입니다(체크 해제로 뺌). 접속마다 어디까지 실행했는지 표시해, 개발 → 테스트 → 의뢰 흐름을 한 곳에서 봅니다.

③ 제약 페이지 편집

「＋」로 종류(PK·UK·FK·CHECK)를 고르면 새 줄이 생깁니다. 열은 목록에서 고르고, FK는 참조 테이블·키를 고릅니다. 이름은 규칙대로 미리 채웁니다(PK_테이블, FK_테이블_01…). 「사용」 칸을 끄면 DISABLE 로 바뀝니다.

④ 인덱스 페이지 편집

열 순서·ASC/DESC 를 칸 안에서 고칩니다. 열을 바꾸면 DROP + CREATE 두 문장이 됩니다(오라클은 인덱스 열 변경이 없음). 테이블스페이스는 접속별 기본값을 쓰고, 고칠 때만 칸을 엽니다.

가상 식 미리보기 AMOUNT = QTY*UNIT_PRICE (SELECT … WHERE ROWNUM <= 5) QTY=2 UNIT_PRICE=1500 → 3000 │ QTY=1 UNIT_PRICE=9900 → 9900 │ QTY=3 UNIT_PRICE=NULL → NULL
