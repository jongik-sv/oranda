  • 쉬운 설정 열 목록 넓히기: DATE·TIMESTAMP 에 더해 ‘날짜처럼 보이는 문자열·숫자’(표본 값이 YYYYMMDD·YYYYMM 형식) 열도 넣습니다. 이 열은 INTERVAL 이 안 되므로 「앞으로 N개월 미리 + MAXVALUE」로 만듭니다.
  • 근거 패널(③ 왼쪽)은 AI 를 쓰지 않아도 「분포 보기」로 따로 열 수 있게 합니다 — AI 설정이 없는 사용자도 숫자를 보고 직접 고를 수 있습니다.

정해 주실 것

  1. 분포 조회 기본값: SAMPLE 1% 로 자동 실행 / 매번 물어보기 / 통계 히스토그램만 사용(실제 SELECT 없음).
  2. 조회 조건 수집(V$SQL): 넣을지. 권한이 없는 계정이 많으면 「건너뜀」 표시만 하고 넘어갑니다.
  3. 값 보내기 기본: 로컬 AI 가 아니면 가림(시안) / 늘 보냄 / 늘 가림.
  4. Tibero: 같은 화면을 쓰되 하위 파티션·INTERVAL 지원 차이를 앱 확인에서 걸러 낼지, 처음엔 Oracle 만 할지.
