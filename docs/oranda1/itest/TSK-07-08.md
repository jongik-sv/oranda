# TSK-07-08 Role 기반 메뉴·기능 통합테스트 결과서

설정 파일에서 Role 을 읽어 **실제 FeatureGate** 를 해석하고, 앱 전체를 조립해(레지스트리·메뉴·도킹·상태 칸·시작 작업·정책 관문·실행 엔진·실제 Oracle) Role 6개와 조합이 PRD 12.2 표대로 움직이는지,
설정 「기능」 탭 → 즉시 반영 / 재시작 안내 → 저장 → 재시작 흐름이 끝까지 가는지, 조회 전용(R6 단독) 실행 차단이 26ai 와 11.2 에서 서버까지 안 간다는 것을 보았다.
앞 레인(07-02~07-06)은 시험 게이트(`FakeFeatureGate`)를 컨테이너에 갈아 끼워 확인했으므로 이 Task 는 그 자리를 전부 실제 게이트로 다시 돌렸다.

## 범위와 규칙

- 실앱 실행·SendKeys 는 하지 않았다. 화면 확인은 Headless 까지이고, 눈으로 봐야 하는 것은 아래 「실앱 눈 확인 목록(사람 몫)」 에 올렸다.
- 별도 DB(TESTDB 등)에는 접속하지 않았다. 비밀번호는 컨테이너 설정에서 환경 변수로만 넘겼고 출력·저장하지 않았다.
- 제품 코드의 결함은 고치지 않았다. 고친 것은 「빠진 문구」 1건(문구 파일 2종 + 그 문구를 단정하던 기존 시험 한 줄)과 11.2 XE 에서 시험 사용자를 못 만들던 시험 도우미 `ItDb`(기본 표 공간 지정 1줄)뿐이다.
- 결함으로 판정한 현재 동작은 `Defect_` 로 시작하는 시험이 「지금 동작」 을 단정해 둔다. 고치면 그 시험이 먼저 알려 준다(TSK-11-04 의 `DEF-nn` 관례).

## Role × 면 (매트릭스 시험이 본 것)

구성 16개 각각 새 앱(데이터 폴더의 `settings.json` → 설정 읽기 → 게이트 해석 → 조립)을 띄워 아래를 정답표와 대조했다.
구성: 설정 없음, R1, R2, R3, R4, R5, R6, R1+R4, R2+R5, R6+R1, 6개 모두, R1+직접 켬 trace+직접 끔 flashback, R6+쓰기 전용 기능 손으로 켬(꺼진 것으로 봐야 함), R6+직접 끔 tableSpec, Role 0개(`roles: []`), 설정 없음+직접 끔 lockMonitor·myBatis.

| 면 | 단정 |
|---|---|
| 게이트 | 켜진 기능 집합 = PRD 12.2 표에서 다시 계산한 집합(D-002 합집합 + 직접 켬 − 직접 끔, D-006 조회 전용은 정확히 `["viewer"]` 일 때만, 쓰기 전용 기능 강제 끔, `plsqlWorkspace` 는 `plsqlEditor` 필요). 시작 직후 `PendingRestart` 비어 있음 |
| 명령 레지스트리 | 282개 모두에 대해 「공통 또는 켜진 기능일 때만 있음」(꼬리표는 제품 `FeatureFor`) + 사람이 정한 명령→기능 표 38개로 꼬리표 자체를 대조 |
| 최상위 메뉴 | 11개 중 「모니터」는 sessionMonitor·lockMonitor·sqlMonitor 가 하나라도 켜졌을 때만, 「튜닝」은 튜닝 묶음 7개 중 하나라도 켜졌을 때만 있음 |
| 메뉴·툴바·우클릭·팔레트 | 꺼진 명령이 하나도 없음. 켜진 명령은 보이는 최상위 메뉴·툴바에 있음. 팔레트 = 레지스트리의 팔레트 명령 |
| 단축키 | 꺼진 명령은 실행 거부(`ExecuteAsync` false), 그 키는 그 명령으로 가지 않음(키맵은 안 지움) |
| 도구 창 | 모든 등록 도구 창이 (공통 또는 켜진 기능)일 때만 있음 + 사람 표 18개. 열린 도구 창 = 기본 배치 ∩ 켜진 것. 보기 메뉴 목록 수 = 레지스트리 수 |
| 상태 칸 | 10개 중 저장 알림(gridEdit)·블로커(blockerAlert)·MyBatis 저장(myBatis)만 기능에 따라 빠짐 |
| 시작 작업 | 14개 중 MyBatis 4개(myBatis)·PL/SQL 작업 공간(plsqlEditor)·변경 일지 기록기(changeJournal)만 기능에 따라 빠짐, 빠진 것 = 건너뜀 목록, `PlSqlWarmUpTask`(공통)는 늘 있음 |

정답표에 일부러 틀린 값을 넣어(`trace` 의 R4 칸) 시험이 실제로 실패하는 것을 확인했다.
