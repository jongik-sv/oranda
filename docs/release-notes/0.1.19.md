# Oranda 0.1.19

## 새 기능

- 접속이 끊기면 상태 표시줄의 접속 칸 옆에 **새로 고침** 단추가 나옵니다. 누르면 그 접속에 다시 접속하고, 지금 탭과 작업 공간은 새 세션을 그대로 씁니다.

## 고친 점

- 대상이 Oracle 11g 인 데이터 복사에서 「테이블 다시 만들기」가 `ORA-00904: "TYPE": 부적합한 식별자`로 실패하던 문제를 고쳤습니다. 사전 점검의 권한 확인도 11g 에서 같은 이유로 실패할 수 있었습니다.
- **파일 > 접속 > 다시 접속**이 끊긴 접속이 아니라 마지막으로 연 접속에 다시 붙던 문제를 고쳤습니다. 이제 지금 보이는 끊긴 접속에 다시 접속합니다.

## 알려진 한계

- 상태 표시줄의 새로 고침 단추는 실제 앱으로 확인하지 않았습니다.
