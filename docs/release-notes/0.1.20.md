# Oranda 0.1.20

## 새 기능

- **스키마 브라우저에 테이블 명**: 테이블·뷰 이름 옆에 테이블 주석(테이블 명)이 흐린 글씨로 보입니다. 이름 필터 칸 옆의 **테이블 명** 체크를 끄면 숨기고, 고른 값은 다음에도 그대로입니다.
- **데이터 복사 「테이블 찾기」**: 테이블 규칙 줄의 **테이블 찾기…** 단추로 창을 엽니다. 이름이나 테이블 명을 치는 대로 목록이 걸러지고(소문자 가능, `*` 와일드카드), 여러 개를 체크해 **선택한 N개 추가**로 한 번에 규칙을 만듭니다. 검색을 바꿔도 고른 표는 남고, 이미 규칙에 있는 표는 흐리게 보입니다. 시노님은 실제 계정·테이블로 풀어 더합니다.
- **데이터 복사 작업 저장**: 규칙 편집 단계에 **저장** 단추와 Ctrl+S 가 생겼습니다. 다른 작업을 열거나 창을 닫을 때도 편집한 내용을 저장합니다. 사전 점검으로 넘어가지 않아도 한 일을 잃지 않습니다.
- **변수를 조건에 넣기**: 변수 줄의 단추를 누르면 고른 규칙의 WHERE 에 `열 IN (:변수)` 가 들어갑니다. 열 이름은 변수 이름에서 찾고(예: `CSM_DOC_NOS` → `CSM_DOC_NO`), 「전체」 규칙이면 「직접 조건」 규칙으로 바꿉니다.
- **실행·검증 작업 로그**: 실행 단계에 실제로 보낸 문장(정리 DELETE, 원본 SELECT, INSERT·MERGE, 배치 커밋, 건수 비교 등)을 시간 순서로 보여 주는 로그가 생겼습니다. 변수 값과 마스킹 값은 남기지 않고 개수만 보입니다. 복사 단추로 전체를 옮길 수 있습니다.

## 고친 점

- 데이터 복사에서 한 번 더한 마스킹을 뺄 방법이 없던 문제를 고쳤습니다. 마스킹 줄마다 오른쪽에 **−** 단추가 생겼고, 뺀 열은 「마스킹할 열 추가…」 목록에 다시 나옵니다.
- 데이터 복사에서 처음 테이블을 입력할 때 자동 완성 후보가 나오지 않던 문제를 고쳤습니다(테이블을 하나 넣은 뒤에야 나왔습니다).
- DDL 일괄 추출의 「이름 바꾸기」에 소문자로 적은 이름(`scott=hr`)이 아무것도 바꾸지 못하던 문제를 고쳤습니다.
- 휴지통 「되살릴 때 새 이름」을 소문자로 적으면 소문자 이름의 표가 생기던 문제를 고쳤습니다. 따옴표 없이 적으면 대문자 이름이 됩니다.

## 알려진 한계

- 이번 기능들은 자동 시험과 화면 그림으로만 확인했고 실제 앱에서 눌러 보지는 않았습니다.
- 원본·대상 「기본 계정」 칸에 글자를 치는 중에 바로 Ctrl+S 를 누르면 방금 친 값은 저장되지 않습니다(칸을 벗어나면 반영됩니다).
