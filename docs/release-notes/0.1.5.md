# Oranda 0.1.5

## 고친 것

- 접속 관리자에서 TNS 디렉터리를 지정한 접속으로 「시험」을 누르면 앱이 꺼지던 문제(ORA-50099)를 고쳤습니다. 이제 TNS 디렉터리와 지갑 위치를 접속마다 따로 넘기므로, 접속마다 다른 TNS 디렉터리를 써도 됩니다.

## 바뀐 것

- 접속 관리자에서 접속 방식을 붙은 단추(호스트·포트 / TNS / 사용자 지정)로 고르고, 고른 방식에 필요한 칸만 보입니다. TNS 디렉터리는 TNS 방식에서만, 지갑 폴더는 지갑을 쓰는 방식에서만 보이고, 숨은 칸 값은 저장하지 않습니다.
- 호스트·포트 방식에서 서비스 이름과 SID 중 하나를 고를 수 있습니다.
