# Oranda 0.1.10

## 고친 것

- macOS 에서 Finder·Dock 으로 연 Oranda 가 AI 튜닝을 시작하면 「claude 실행 파일을 찾지 못했습니다」 로 멈추던 것을 고쳤습니다. 이렇게 연 앱은 터미널의 PATH 를 받지 못해 Homebrew·npm 으로 설치한 claude 를 찾지 못했습니다. 이제 PATH 에 없으면 흔한 설치 위치(`~/.local/bin`, `/opt/homebrew/bin`, `/usr/local/bin` 등)도 찾아봅니다.

## 바뀐 것

- 설치 파일 크기 목표를 80 MB 에서 100 MB 로 올렸습니다.
- AI 튜닝이 인덱스를 제안할 때 그 표에 이미 있는 인덱스를 먼저 봅니다. 앞 열이 같은 인덱스가 있으면 새로 만들지 않고 그 인덱스에 열을 더하거나 순서를 바꾸는 안(「기존 … 로 변형」)을 먼저 보여 주고, 기존 인덱스가 이미 덮는 후보는 뺍니다. 열은 조건·조인 열만 4개 이하로 하고, 5개 이상이면 경고를 답니다.
