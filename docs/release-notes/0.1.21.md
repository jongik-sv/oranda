# Oranda 0.1.21

## 새 기능

- **데이터 복사 「대상에 표가 없으면 만들기」**: 테이블 규칙에 **대상에 표가 없으면 원본 구조로 만들기** 체크가 생겼습니다(기본 꺼짐). 켜면 대상 계정에 같은 이름의 표가 없을 때 사전 점검이 오류 대신 「만들 표」와 만들 문장(DDL) 미리 보기를 보여 주고, 실행하면 표를 만든 뒤 데이터를 넣습니다.
  - 열·PK·UK·CHECK·작업 안 표끼리의 FK·인덱스·주석을 함께 만듭니다. 트리거·권한·시노님은 만들지 않습니다.
  - 개발 접속에서만 쓸 수 있습니다(「테이블 다시 만들기」와 같은 조건). 운영 접속이면 지금처럼 「대상 표 없음」 오류가 납니다.
  - 데이터 넣기가 실패하면 방금 만든 표를 지웁니다(휴지통에 남기지 않음).
  - 대상 처리가 「테이블 다시 만들기」이면 이 체크는 쓸 수 없습니다.
  - 대상 표가 이미 있으면 체크와 상관없이 예전과 같습니다.

## 고친 점

- 작업 공간을 바꿨다 돌아오면 편집기 스크롤 위치가 맨 위로 돌아가던 문제를 고쳤습니다.

## 알려진 한계

- 복사 작업 저장 파일의 형식 버전이 올라갔습니다(3 → 4). 예전 파일은 그대로 열리지만(새 체크는 꺼진 채), 이 버전에서 저장한 파일은 0.1.20 이하에서 열 수 없습니다.
- 「대상에 표가 없으면 만들기」는 자동 시험(Oracle 통합 시험 포함)으로만 확인했고 실제 앱에서 눌러 보지는 않았습니다.
