# Oranda 0.1.30

## 새 기능

- **스키마 브라우저에서 통계 수집**: 테이블을 오른쪽 단추로 눌러 「통계 수집…」을 고르면 확인 창이 열립니다. 「통계 보기」 탭에서도 「통계 수집 실행…」으로 같은 창을 엽니다.
  - 표본 비율, 열 히스토그램, 인덱스 통계 함께(CASCADE), 병렬 정도를 고르면 보낼 PL/SQL 이 바로 바뀌어 보입니다. 「수집 멈추기」로 도중에 멈출 수 있습니다. 「스크립트로 열기」를 누르면 실행하지 않고 같은 문장을 새 편집기 탭에 넣습니다.
  - 운영 접속이면 경고가 보입니다. 확인은 한 번만 묻고, 지금 작업을 막지 않도록 같은 접속의 전용 세션에서 실행합니다.
  - 끝나면 열 통계 요약과 열린 「통계 보기」를 새로 읽습니다.
  - Tibero 는 지원하지 않는 선택(자동 cascade·무효화 시점)을 빼고 문장을 만듭니다.
- **열 통계 요약**: 스키마 브라우저 속성 창에서 열을 고르면 서로 다른 값 수, NULL 수, 최솟값·최댓값, 작은 히스토그램이 보입니다. 「통계 보기」 탭에도 최솟값·최댓값 열이 생겼습니다.
- **크기를 K·M·G·T 로 표시**: 바이트 수가 큰 칸(객체 상세의 크기, 객체 찾기, 원복 설정, 트레이스, LOB, 통계 보기 등)을 `1.5 M` 처럼 소수점 한 자리로 보입니다. 마우스를 올리면 정확한 바이트 수가 나오고, 복사와 정렬은 원래 숫자로 합니다.

## 고친 점

- **객체 상세가 늦게 뜨던 문제**: 테이블을 고르면 지금 보고 있는 탭부터 읽어 바로 보입니다. 다른 탭은 고를 때 읽고, DDL 은 DDL 탭을 고를 때 읽습니다. 내용이 없는 탭에는 「없음」이 나옵니다.
- **열 통계 값이 알 수 없는 숫자로 보이던 문제**: Oracle 의 최솟값·최댓값과 히스토그램 끝값이 내부 형식(RAW·큰 숫자)으로 보이던 것을 실제 값(문자, 숫자, 날짜, 시각, 간격)으로 풀어 보입니다. Oracle 11g 와 Tibero 도 같습니다.
- **새 기능 창**: 릴리스 노트의 `**굵게**` 와 `` `코드` `` 표기를 그대로 보이던 문제를 고치고, 창을 넓혀 크기를 바꿀 수 있게 했습니다.
