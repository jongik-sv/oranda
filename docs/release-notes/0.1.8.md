# Oranda 0.1.8

## 새 기능

- AI 튜닝이 생겼습니다. 편집기에서 커서가 있는 문장을 툴바의 「AI 튜닝」 분할 단추(또는 튜닝 메뉴)로 보내면, 시작 창에서 보낼 것·요청하면 보낼 것·보내지 않는 것과 모델(opus·sonnet·haiku)·생각 깊이를 확인한 뒤 오른쪽 「AI 대화」 창에서 튜닝이 진행됩니다. AI 는 Oranda 가 허락한 도구(실행 계획·실제 계획·SQL 수행 통계·표·인덱스·통계 조회, 변형 성능 비교)만 쓰고, 도구 호출은 대화 창에 카드로 보이며 모두 감사 기록에 남습니다. 재작성 제안은 제안 카드로 오고, 비교 창에서 받아들일 때만 편집기 글이 바뀝니다. 인덱스 후보는 새 탭으로 엽니다. 이 PC 에 Claude Code(claude 실행 파일)가 있어야 합니다.
  - 접속마다 AI 허용 수준(끔·메타데이터·계획·조회 실행·조회 + 행 값)을 정합니다. 운영 접속은 「조회 실행」까지만 허용하고, 문장의 리터럴 값과 주석 내용은 자리표시(`:v1`·`/*c1*/`)로 바꿔 보낸 뒤 제안에서 원래 값과 주석으로 되돌립니다(설정에서 운영이 아닌 접속에도 켤 수 있음). 행 값·히스토그램 끝값·비밀번호·호스트는 보내지 않습니다.
  - 변형 성능 비교는 SELECT 만 실제로 실행하고, 운영 접속에서는 문장마다 30초를 넘기면 멈춥니다. 문장에 바인드 변수가 있으면 튜닝을 시작한 탭의 바인드 변수 창 값으로 로컬에서 실행합니다(값은 AI 에 보내지 않음, 비밀번호처럼 보이는 이름은 쓰지 않음). 실패하면 이유를 대화에 알리고 Oranda 로그에 남깁니다.
  - 비교 창은 탭 2개입니다. 「바뀐 부분 비교」는 왼쪽에 기존, 오른쪽에 변경을 나란히 보이고, 「현재 / 제안」 탭에서는 제안 글을 고친 뒤 적용할 수 있습니다. AI 가 제안에서 주석을 빠뜨리면 대화에 「주석 n개 빠짐」으로 알립니다.
- 결과 탭 이름 옆에 문장 실행 시간이 보입니다(예 「결과 1 (3.2s)」).
- SQL 탭 오른쪽 클릭 메뉴에 「탭 복사(새 탭에)」가 생겼습니다. SQL 과 함께 바인드 변수 창의 줄(값·자료형·방향)도 복사합니다.
- 툴바의 「저장」 옆에 「작업 공간 저장」 단추가 생겼습니다.
- 바인드 변수 창에서 줄을 끌어 여러 줄을 한꺼번에 고를 수 있고, 오른쪽 클릭 메뉴에 「전체 복사」가 생겼습니다. 실행하기 전인 새 탭에도 붙여 넣으면, 그 탭의 SQL 이 쓰는 이름의 줄을 만들어 채웁니다.
- 실행 계획 트리의 열 너비를 끌어 바꿀 수 있고(바꾼 너비를 기억함), 계획 트리를 접고 펼 수 있습니다.

## 바뀐 것

- 바인드 변수 값이 작업 공간(자동 저장·`.workspace.md`)과 `.sql` 파일에 모두 저장됩니다. SQL 이 쓰는 바인드는 값이 없어도 NULL 로 저장되어, 다시 열면 어떤 변수가 있는지 바로 보입니다. 비밀번호처럼 보이는 이름의 값도 저장하므로, 파일을 나눌 때 그 값이 함께 나갑니다.
- 실제 실행 계획(A-Rows)이 필요하면 SELECT·WITH 문장을 자동으로 다시 실행하는 동작이 기본으로 켜졌습니다. 다시 실행 중에는 취소 단추가 보이고, 설정에서 끌 수 있습니다.
- 스키마 브라우저와 객체 찾기의 유형 고르기(「모든 유형」)가 체크 목록이 됐습니다. 펼치면 맨 위 「전체 선택」 과 유형마다 체크 상자가 있어 여러 유형(예 TABLE·VIEW)을 함께 고를 수 있고, 체크하는 대로 트리에 바로 반영됩니다(목록은 열린 채로 남고 Space 로 체크, Esc 로 닫음). 닫힌 글은 「모든 유형」·「TABLE, VIEW」·「TABLE, VIEW 외 2」 처럼 보이며, 아무것도 고르지 않으면 모든 유형을 봅니다. 스키마 브라우저에서 고른 유형은 접속마다 기억하고, 필터 지우기는 모든 유형으로 되돌립니다.

## 고친 것

- 자동완성 단축키(macOS Option+Esc, Windows Ctrl+Space)가 PL/SQL 편집기나 MyBatis 문장 탭에서 눌러도 그 편집기가 아니라 SQL 탭에 열리거나 아무것도 하지 않던 것을 고쳤습니다. macOS 에서 Option+Esc 바로 뒤에 친 글자가 사라지던 것도 고쳤습니다.
- macOS 에서 이름이 한글인 탭(예 「원본」)을 저장하면 파일 이름이 「원본.sql.sql」 로 되던 것을 고쳤습니다. 저장하는 한글 파일 이름은 Windows 에서도 자모가 갈라지지 않게 맞춥니다.
- 매퍼 폴더 트리를 연 채 xml 에 저장할 때, 폴더 감시가 파일을 잠깐 잡고 있으면 「쓰지 못했습니다」 로 저장이 실패하던 일을 고쳤습니다(Windows). 잠깐 잡힌 경우 몇 번 다시 시도해 저장합니다.
