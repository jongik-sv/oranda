# Oranda 0.1.8

## 바뀐 것

- 스키마 브라우저와 객체 찾기의 유형 고르기(「모든 유형」)가 체크 목록이 됐습니다. 펼치면 맨 위 「전체 선택」 과 유형마다 체크 상자가 있어 여러 유형(예 TABLE·VIEW)을 함께 고를 수 있고, 체크하는 대로 트리에 바로 반영됩니다(목록은 열린 채로 남고 Space 로 체크, Esc 로 닫음). 닫힌 글은 「모든 유형」·「TABLE, VIEW」·「TABLE, VIEW 외 2」 처럼 보이며, 아무것도 고르지 않으면 모든 유형을 봅니다. 스키마 브라우저에서 고른 유형은 접속마다 기억하고, 필터 지우기는 모든 유형으로 되돌립니다.

## 고친 것

- 매퍼 폴더 트리를 연 채 xml 에 저장할 때, 폴더 감시가 파일을 잠깐 잡고 있으면 「쓰지 못했습니다」 로 저장이 실패하던 일을 고쳤습니다(Windows). 잠깐 잡힌 경우 몇 번 다시 시도해 저장합니다.
