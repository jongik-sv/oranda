# Oranda 0.1.3

## 바뀐 것

- 앱 아이콘이 바뀌었습니다. Windows 는 오렌지 「O」 아이콘(창·작업 표시줄·설치 파일), macOS 는 Oranda 마스코트 아이콘입니다.
- 조회가 실행 중이면 그 SQL 탭(MyBatis·PL/SQL 실행 포함) 머리와 그 탭이 든 작업 공간 탭 머리에 주황 스피너가 돕니다. 다른 탭을 보고 있어도 남고, 스피너에 마우스를 올리면 「실행 중 · 경과 n초」가 보입니다. 결과 창 위에도 「실행 중 · 경과 n초」 띠가 나옵니다. 끝나거나 오류·취소로 멈추면 사라집니다.
- 「매퍼 쿼리」 목록과 매퍼 폴더 트리에서 편집기 탭으로 열린 쿼리는 이름이 굵고 왼쪽에 막대가 보이며, 지금 보고 있는 탭의 쿼리는 파란 막대로 따로 보입니다. 저장 안 한 고침은 ●, xml 에 저장해 매퍼를 연 때와 달라진 쿼리는 ○ 로 보입니다. 목록 위 「열림 n」·「변경 n」 단추를 누르면 그 쿼리만 거릅니다.

## 고친 것

- 스크립트 창에서 새 스크립트를 만들거나 파일을 열면, 왼쪽 탭(스키마 브라우저·스크립트)을 오간 횟수만큼 같은 파일이 편집기 탭 여러 개로 열리던 것을 고쳤습니다. 이제 한 파일은 탭 하나로 열립니다.
- 개인 계정으로 접속해 시노님(개인·PUBLIC)으로 다른 스키마의 표를 조회한 결과에서 플래시백(N분 전 값 보기·이 행 변경 이력·이전 값으로 되돌리기)이 표를 접속 계정 스키마에서 찾아 실패하던 문제를 고쳤습니다. 이제 시노님을 따라 실제 소유자의 표로 읽고 되돌립니다(DB 링크 시노님은 지원하지 않는다고 알립니다). 「이 행 변경 이력」이 운영 DB에서 ORA-08180으로 실패하던 문제도 고쳤습니다. 이제 기본으로 최근 1.5일(`VERSIONS BETWEEN TIMESTAMP SYSDATE - 1.5`)을 읽고, 설정 > 결과 그리드 「변경 추적 기간」에서 일수를 바꾸거나 가능한 전체 기간으로 고를 수 있으며, 「변경 추적하기」를 끄면 그 메뉴가 숨습니다.
