# Oranda 0.1.32

## 새 기능

- **AI 연결 도우미**: AI 를 처음 연결하는 사람이 단추만 눌러 따라 하면 되는 창입니다.
  - 도구 > AI 연결 도우미… 에서 엽니다. AI 가 아직 연결되지 않았으면 처음 실행할 때 한 번 묻고, AI 명령이 「AI 가 아직 연결되지 않았습니다」 로 멈추면 그 자리에 「AI 연결 도우미 열기」 단추가 나옵니다.
  - 회사 Claude 계정: 설치 → 로그인 → 연결 시험을 도우미가 대신 합니다. 자동 설치가 안 되면 붙여 넣을 한 줄과 「복사」 단추를 보여 줍니다.
  - 회사 AI 서버: 담당자에게 받은 설정 파일(`.oranda-ai`)이나 서버 주소로 연결하고 시험합니다.
  - 잘 모르겠으면 담당자에게 보낼 글을 만들어 줍니다.
  - 끝에 AI 를 쓸 접속을 고르고, 예제 SQL 로 「해 보기」 를 해 봅니다. 중간에 닫아도 다음에 연 곳부터 이어 합니다.
- **외부 에이전트 연결**: 밖에서 띄운 Claude Code, Codex, Antigravity, opencode 가 실행 중인 Oranda 를 `orandactl` 로 다룹니다.
  - 도구 > 외부 에이전트 연결… 에서 쓸 접속을 고르고 「연결」 합니다. 기본 8시간 뒤 끊기고, 상태 표시줄의 「끊기」 로 바로 끊습니다.
  - 「스킬 설치…」 로 각 CLI 에 `oranda` 스킬을 넣습니다.
  - 에이전트는 탭 글 읽기, 편집 제안(제안 막대에서 사람이 받아들임), 새 탭, 메타데이터·계획 조회, SELECT 실행, 결과를 xlsx·csv 로 저장, AI 튜닝 시작, 메뉴 명령 실행, 매뉴얼 링크 찾기를 할 수 있습니다.
  - 바꾸는 문장(INSERT·UPDATE·DDL 등)은 실행하지 않습니다. 운영 접속은 연결할 때 접속 이름을 다시 입력해야 고를 수 있고, SELECT 를 돌려도 회사 밖 AI 에는 행 수만 갑니다(2026-11-24 바로잡음: 처음 노트에는 「운영은 기본으로 메타데이터만」 이라고 잘못 적었습니다).

## 고친 점

- **통계 수집 결과가 바로 안 보이던 문제**: 통계를 수집하면 열려 있는 테이블 창의 통계·파티션·크기 탭과 스키마 브라우저 속성이 바로 새 값으로 바뀝니다. 편집기에서 `DBMS_STATS.GATHER_TABLE_STATS` 를 실행해도 같습니다(Oracle·Tibero).
- **통계 수집 창**: 다 성공하면 저절로 닫히고, 실패하거나 취소하면 남습니다. 「백그라운드로 실행」 을 누르면 창을 닫고 계속 돌며 끝나면 스키마 브라우저 상태 줄에 알려 줍니다.
