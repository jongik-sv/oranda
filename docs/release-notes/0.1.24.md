# Oranda 0.1.24

## 새 기능

- **좁게 도킹한 실행 이력·변경 일지**: 창 폭이 좁으면(560 이하) 표 대신 카드 목록으로 바뀝니다. 폭을 바꾸면 바로 전환됩니다.
  - 실행 이력: 카드마다 문장과 결과를 보이고, 도구 막대는 거르기 칩과 「더 보기」 메뉴로 줄어듭니다. 고른 문장 아래에 오류 전문이 나옵니다.
  - 변경 일지: 카드에 원인과 원복 상태를 표시합니다. 「실행한 문장」과 「원복 스크립트」가 위아래로 놓이고 각각 복사 단추가 있습니다.
- 실행 이력 창은 처음에 왼쪽 묶음에 들어갑니다(닫힌 상태, 열면 나옴). 이미 저장한 배치는 그대로 둡니다.
- **매뉴얼**: 좁은 도킹 안내와 그림을 더했고, 그리드 편집 도구 막대 그림을 새 아이콘으로 다시 찍었습니다.

## 고친 점

- 원복 실행이 변경 일지에 「원복 스크립트 #N 실행」 한 줄만 남기던 것을 고쳤습니다. 이제 실제로 실행한 문장마다 기록하고, 문장마다 실행 직전 시점을 함께 남깁니다. 변경 일지에서 이 문장들의 원인은 「원복 실행(#N)」으로 보입니다.
- 「이 실행 전과 비교」 반영의 변경 일지 요약에서 행 값을 가립니다.

## 내부 정리

- 동작은 바꾸지 않고 코드 구조를 정리했습니다. 큰 파일(데이터 복사, 잠금 모니터, 튜닝 보고서, 도킹 배치 등)을 책임별로 나누고, Oracle·Tibero 에 따로 있던 같은 코드를 한곳으로 모았습니다.
- 흔들리던 자동 시험이 정해진 시간 대신 조건을 기다리도록 바꿨습니다.
