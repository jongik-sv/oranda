# Oranda 0.1.17

## 새 기능

- 데이터 복사가 생겼습니다. **도구 > 데이터 복사…**에서 한 접속의 표 데이터를 다른 접속의 표로 복사합니다. 규칙 편집, 사전 점검, 실행·검증 세 단계로 진행하고, 설정은 작업으로 저장해 다시 실행할 수 있습니다.
  - 표마다 전체, 기간, 부모 키, 직접 조건 규칙을 고르고, 대상은 같은 범위 지우고 넣기, 전체 지우고 넣기, 추가만, 기본키 MERGE 가운데 고릅니다. 개발 접속이 대상이면 테이블 다시 만들기도 고를 수 있습니다.
  - 기간 규칙에 추가 조건(AND)을 붙일 수 있고, 열마다 마스킹(고정값, 앞·뒤 남기기, 해시, NULL)과 건너뛸 열을 정합니다.
  - 기간을 직접 지정할 때 끝 날짜를 「미만」으로 셀지 「끝 날짜 포함」으로 셀지 고릅니다.
  - 「전기일」로 업무 날짜가 바뀌는 시각을 정할 수 있습니다. 7로 두면 DATE·TIMESTAMP 기간 열의 하루를 07:00부터 다음 날 07:00 전까지로 셉니다. 문자열로 저장한 날짜 열에는 쓰지 않습니다.
  - 표를 시노님 이름으로 넣으면 실제 계정과 표로 풀고, 규칙마다 원본 계정과 대상 계정을 정합니다.
  - 사전 점검은 권한, 열 차이, 실행할 SQL을 보여 주고, 실행·검증 단계는 원본과 대상 건수를 비교하고 실패한 행을 다시 넣을 수 있습니다.
- 결과 그리드에서 `Ctrl`을 누른 채 열 머리글을 눌러 떨어진 열 여러 개를 고르고, 셀을 끌어 범위를 더할 수 있습니다. 복사와 CSV·Excel 「선택」 내보내기가 고른 열만 화면 순서대로 씁니다.
- 바인드 변수 창에 **값 비우기** 단추가 생겼습니다. 이름, 형식, 방향은 그대로 두고 값만 비웁니다.
- 상태 표시줄의 업데이트 표시가 색 배지로 바뀌었습니다. 새 버전이 있으면 주황, 내려받는 중이면 파랑, 적용 준비가 끝나면 초록입니다. 업데이트 띠도 상태 색으로 채워 눈에 잘 띕니다.

## 알려진 한계

- 운영 접속은 데이터 복사의 대상으로 쓸 수 없습니다. 원본으로만 씁니다.
- 사전 점검은 원본의 복사할 행 수를 미리 세지 않습니다. 건수는 실행·검증 단계에서 나옵니다.
- 데이터 복사 창에서 **F1**을 눌러도 설명서가 열리지 않습니다. 설명서의 「데이터 복사」 쪽을 직접 여세요.
- 좁은 창(폭 1280 이하)에서는 규칙 그리드에 가로 스크롤이 생기고 「조건」 칸이 잘려 보일 수 있습니다.
- 데이터 복사의 시노님 추가(개인·PUBLIC·DB 링크)와 스키마 브라우저의 시노님 노드 추가, 다른 계정에 쓸 때의 확인 창은 실제 앱으로 확인하지 않았습니다. macOS에서는 데이터 복사 창 전체를 실제 앱으로 확인하지 않았습니다.
- 설명서의 데이터 복사 그림 일부는 Windows 글꼴로 그려졌습니다.
