# Oranda 0.1.15

## 새 기능

- SQL 편집기에서 여러 줄을 한 번에 고칠 수 있습니다. `Alt`(macOS는 `Option`)를 누른 채 누르면 커서가 늘어나고, 누른 채 끌면 네모난 열 블록이 선택됩니다. 선택 실행은 블록 안의 글만 실행합니다.
- 테이블 이름을 쓰는 자리에서 자동 완성이 저절로 열립니다. `FROM`이나 `JOIN` 뒤에 스키마 없이 이름을 두 글자 이상 입력하고 잠깐 멈추면 목록이 나옵니다. 목록이 떠 있어도 실행 키는 쿼리를 실행합니다.
- 스키마 없이 입력한 테이블 이름의 자동 완성 후보에 PUBLIC 시노님과 다른 스키마의 테이블, 뷰가 함께 나옵니다. 다른 스키마의 후보를 고르면 스키마 이름까지 함께 들어갑니다.
- 결과 탭에 필터 버튼과 결과 편집 모드 버튼이 생겼습니다.
- 결과 그리드의 열 머리글이나 값을 두 번 누르면 열 이름이나 값을 SQL 편집기에 넣습니다. 편집 모드의 결과에서 값을 두 번 누르면 전처럼 셀 편집이 열립니다.
- 셀을 편집하는 중에 `↑`, `↓`로 위아래 행으로 옮겨 갈 수 있습니다.
- 결과 그리드의 오른쪽 클릭 메뉴와 **결과** 메뉴에서 오름차순 정렬, 내림차순 정렬, 정렬 해제를 「열」 하위 메뉴가 아니라 바로 고를 수 있습니다.
- 테이블 레이아웃 창에 여러 표를 탭으로 열 수 있습니다. 탭을 창 밖으로 끌면 새 창으로 분리되고, 다른 테이블 레이아웃 창에 끌어다 놓으면 합쳐집니다.
- macOS에서 한글을 입력할 때 조합 중인 글자가 커서 자리에 밑줄과 함께 바로 보입니다.

## 고친 것

- macOS에서 한글을 조합하는 중에 `Enter`를 두 번 눌러야 줄이 바뀌던 것을 고쳤습니다. 이제 한 번에 글자가 확정되고 줄이 바뀝니다.
- 도구 창을 켜거나 끌 때 나누어 둔 문서 영역이 합쳐지던 것을 고쳤습니다.
- 자동 완성 목록이 열린 채 실행 키를 누르면 쿼리를 실행한 뒤에도 목록이 남아 있던 것을 고쳤습니다.

## 알려진 한계

- Windows에서 `Alt` 클릭, `Alt` 끌기, MS IME 한글 입력은 실제 키보드로 아직 확인하지 않았습니다.
- macOS에서 조합 중 `Enter`로 한자 후보를 고르는 동작은 실제 키보드로 확인하지 않았습니다.
- macOS에서 한글을 입력할 때 드물게 첫 단어의 글자가 빠지는 것을 시험 중에 보았지만 원인을 찾지 못했습니다.
- 실행 취소를 하면 추가한 커서가 사라집니다. `Ctrl+Backspace`처럼 단어 단위로 지우는 키는 주 커서에만 적용됩니다.
- 처음 접속한 DB는 객체 목록을 다 읽은 뒤부터 다른 스키마 후보가 나옵니다.
- 나누어 둔 문서 영역은 앱을 다시 시작하면 하나로 합쳐집니다.
