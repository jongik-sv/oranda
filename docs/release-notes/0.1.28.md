# Oranda 0.1.28

## 새 기능

- **주 모델과 가벼운 일 모델**: AI 설정의 「AI 모델」에 「가벼운 일 모델」 줄이 생겼습니다. SQL 설명, 오류 고치기, 요약처럼 간단한 일은 이 모델로, 튜닝처럼 복잡한 일은 주 모델로 보냅니다.
  - 「주 모델과 같음」(기본), Claude Code · haiku·sonnet, 저장된 프로필(로컬 AI 포함), 시스템·기타 CLI 가운데 고릅니다. 로컬 AI 프로필이 없으면 haiku 에 「추천」이 붙습니다.
  - 보낼 내용이 가벼운 일 모델 입력 한도의 70% 를 넘으면 저절로 주 모델로 보내고 「입력이 커서 주 모델로 보냈습니다.」를 남깁니다.
  - 받는 곳 확인과 값 가리기는 실제로 보내는 모델 기준으로 합니다. 가벼운 일 모델이 실패해도 다른 모델로 몰래 넘기지 않고 「주 모델로 다시 보내기」를 보입니다.
  - 답 머리에 실제로 답한 모델 이름이 작게 나옵니다. 감사 기록에도 등급과 모델 이름을 남깁니다.
- **로컬 AI 입력 한도**: Ollama·LM Studio 로 새 프로필을 만들면 「최대 입력 토큰」 기본값이 8,192 입니다. 「연결 확인」 때 서버가 알려 주는 모델 문맥 크기로 이 칸을 채웁니다.
- **화면에서 바로 쓰는 AI**: 대화가 필요 없는 일은 그 화면 안의 작은 AI 띠에 답이 바로 나옵니다. 「채팅에서 이어 보기」를 누르면 보낸 정보와 답을 그대로 AI 대화 창으로 옮깁니다.
  - **오류 고치기**(SQL 편집기·PL/SQL 편집기): 편집기 아래 막대에 원인과 고친 글이 나오고, 「받아들이기」를 누르면 차이 미리보기로 그 자리에 넣습니다. 실행·컴파일은 직접 합니다.
  - **Lock 모니터 「✨ AI 풀이」·세션 모니터 「✨ 대기 풀이」**: 상황·원인 추정·권하는 행동을 보여 줍니다. 「더 깊게」는 주 모델로 대화 창에 새 대화를 엽니다. 세션 종료 확인 창에 받은 풀이의 결론 한 줄이 보입니다.
  - **실행 전 AI 검토**: 반영 묶음 실행 창과 테이블 편집 DDL 미리보기에서 「AI 검토」를 누르면 위험도, 잠금·무효화·공간·시간·되돌리기 표, 권하는 실행 순서를 보여 줍니다. 실행 단추는 막지 않습니다.
  - **변경 일지 「✨ 이 기간 요약」·플래시백 「✨ 차이 요약」·원복 스크립트 「✨ AI 점검」**: 원복 점검은 빠진 행과 FK 순서를 짚고, 고친 스크립트를 편집기에 제안으로 넣습니다.
- **AI 대화 창에서 하는 일**
  - **SQL 모니터 AWR 이력 「AI로 원인 보기」**: 같은 SQL 의 실행 계획이 바뀌었을 때 AWR 이력과 저장 계획을 살펴 원인과 조치를 알려 줍니다. 계획을 고정하는 SQL Plan Baseline 스크립트를 편집기에 넣을 수 있습니다.
  - **PL/SQL 코드 설명**: PL/SQL 편집기에서도 「SQL 설명」을 쓸 수 있습니다.
  - **MyBatis 펼친 SQL**: MyBatis 작업 공간의 문장 탭에서 지금 값으로 펼친 SQL 을 튜닝하고 설명합니다. 제안은 새 SQL 탭에 들어가고 매퍼 XML 은 바뀌지 않습니다.
- **Linux 비밀번호 저장**: Linux 에서 접속 프로필의 「비밀번호 저장」이 시스템 키링(Secret Service)에 저장되어 앱을 다시 켜도 남습니다. 키링을 쓸 수 없으면 전처럼 앱이 켜져 있는 동안만 기억합니다. 키링을 쓰면 Linux 에서도 원복 스크립트를 만듭니다.

## 고친 점

- Oracle PDB 에 접속했을 때 SQL 모니터 AWR 이력의 「두 plan_hash 비교」가 계획 줄을 보여 주지 못하던 문제를 고쳤습니다.
