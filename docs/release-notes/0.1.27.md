# Oranda 0.1.27

## 새 기능

- **AI 파티션 추천**: 테이블 편집기의 「파티션」 페이지에서 **AI 추천…**을 누르면, 앱이 통계·값 분포·PK·인덱스 정보를 모아 AI에게 보내고 어떤 열로 어떻게 나눌지 추천을 받습니다.
  - 날짜·타임스탬프 열뿐 아니라 문자열로 된 날짜 열, 숫자·문자열 RANGE, 코드 값의 LIST, HASH, 하위 파티션까지 추천합니다.
  - 보내기 전에 확인 창에서 보낼 정보와 실제 값을 가릴지 고릅니다.
  - 응답은 AI 대화 창에 나옵니다. 후보마다 AI의 이유와 앱이 직접 확인한 결과(✔⚠✖)를 보여 주고, **편집기에 채우기**로 파티션 편집기에 바로 채웁니다. 실행은 직접 검토한 뒤 합니다.
  - 같은 대화에서 이어서 물으면 새 후보를 다시 받고 다시 확인합니다. 결과는 보고서(HTML)로 저장할 수 있습니다.
  - **분포 보기**로 AI 없이 근거(분포·통계)만 볼 수도 있습니다.
- **파티션 편집**
  - 문자열로 된 날짜 열(`YYYYMMDD` 등)도 쉬운 설정으로 나눌 수 있습니다.
  - 하위 파티션 템플릿과 LOCAL 인덱스를 편집기에서 정합니다.
  - 자동 추가(INTERVAL)를 못 쓰는 경우 「월 추가 스크립트 저장…」으로 달마다 파티션을 더하는 스크립트를 만듭니다.
  - Tibero와 Oracle 12.2 미만처럼 한 문장으로 파티션 테이블로 못 바꾸는 서버에서는 「다시 만들기 스크립트」를 만듭니다. 이때 아래 줄의 「스크립트 저장…」과 DDL 미리보기도 이 스크립트를 쓰고, 「실행」은 이유를 알려 주며 막습니다.
- **스크립트 실행 위치 표시**: 여러 문장을 실행하면 지금 실행 중인 문장으로 커서가 따라가고 옅은 색으로 표시됩니다. 오류로 멈추면 그 문장에 표시가 남습니다.

## 고친 점

- 테이블 편집기의 열·제약·인덱스·파티션·저장 표를 앱의 다른 표와 같은 모양(머리글, 칸 선, 줄 높이, 숫자 오른쪽 정렬)으로 바꿨습니다.
