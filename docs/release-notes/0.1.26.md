# Oranda 0.1.26

## 새 기능

- **테이블 편집기**: 객체 상세 창에서 **✎ 편집**을 켜고 테이블 구조를 표에서 고칩니다. 바뀐 만큼의 DDL이 바로 보이고, 실행하거나 의뢰용 `.sql` 스크립트로 저장합니다.
  - 열(가상 열, 신원, 숨김, 도메인 포함), 제약, 인덱스(함수 기반, 비트맵), 설명, 테이블 이름을 고칩니다.
  - 열 형식을 바꿀 때 데이터가 있으면 새 열로 옮겨 바꾸는 순서를 대신 만듭니다.
  - 「저장」 페이지에서 테이블스페이스, PCTFREE, 압축, LOGGING, 병렬, LOB 저장 절을 고칩니다. 보기 모드에서도 지금 값이 보입니다.
  - 「파티션」 페이지: 날짜 열과 「매일·매월·매년」만 고르면 파티션 테이블로 바꿉니다. 자동 추가(INTERVAL)를 켜고 끌 수 있고, 「＋ 다음 파티션」이 다음 경계값과 이름을 채웁니다. 경계값은 `2027-01-01` 처럼 그냥 적습니다.
  - 실행 전 검사가 데이터를 먼저 읽어, 새 길이를 넘는 행·NULL 행·겹치는 키처럼 실패가 확실한 변경은 막고, 되돌릴 수 없는 지우기나 오래 잠그는 변경은 알려 줍니다.
  - 스키마 브라우저에서 새 테이블 탭을 열어 새 테이블을 만듭니다. 만들던 내용은 저장해 두었다가 다시 이어서 씁니다.
  - Oracle과 Tibero를 모두 지원합니다.
- **반영 묶음**(도구 > 반영 묶음): 개발하면서 실행한 DDL을 이름 붙인 묶음에 모으고, 어느 DB까지 실행했는지 표시하고, 체크한 문장만 의뢰용 `.sql` 파일 하나로 저장합니다. 묶음을 실행할 때는 먼저 검사하고 한 번만 확인합니다.
- **매뉴얼**: 테이블 편집기 쪽을 새로 쓰고 그림을 넣었습니다.

## 고친 점

- 열을 더하거나 지운 뒤 같은 테이블의 「데이터」 탭이 「Index was outside the bounds of the array」로 열리지 않던 것을 고쳤습니다.
- UI 언어를 영어로 바꿔도 스키마 브라우저의 분류 이름이 한국어로 남던 것을 고쳤습니다.
- 실행 이력 창에서 「다시 실행」 단추를 뺐습니다.
