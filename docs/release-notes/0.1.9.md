# Oranda 0.1.9

## 새 기능

- AI 대화 창에서 이미 적용한 재작성 제안 카드에도 「비교 보기」 단추가 생겼습니다. 누르면 「바뀐 부분 비교」(왼쪽 원본·오른쪽 적용한 글)와 「원본 / 적용한 제안」 두 탭으로 된 창이 열립니다. 이 창은 보기 전용이라 편집기 글을 바꾸지 않습니다.

## 고친 것

- 설치판(macOS·Windows)에서 AI 튜닝을 시작하면 「orandactl 실행 파일을 찾지 못했습니다」 오류로 멈추던 것을 고쳤습니다. 설치 패키지에 orandactl 이 빠져 있었습니다.
- 「작업 공간 이름 바꾸기」 뒤 「작업 공간 저장」 을 하면 이름이 원래대로 돌아가던 것을 고쳤습니다. 이제 바꾼 이름이 남고, 파일도 같은 폴더에서 새 이름(`새이름.workspace.md`)으로 옮깁니다. 그 이름의 파일이 이미 있으면 덮어쓰지 않고 저장 위치를 묻습니다.
