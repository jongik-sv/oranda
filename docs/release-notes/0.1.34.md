# Oranda 0.1.34

## 고친 점

- **운영 접속을 고를 때 이름을 두 번 묻던 문제**: 설정 > AI 의 「AI 가 볼 수 있는 접속」 표에서 수준을 직접 정해 둔 운영 접속은, 외부 에이전트 연결 창에서 접속 이름을 다시 묻지 않습니다. 표에서 손대지 않아 처음 값 그대로인 운영 접속만 지금처럼 묻습니다.
- **상태 표시줄에 「끊기」 만 보이던 문제**: 운영 접속을 쓰면 상태 표시줄 바탕과 에이전트 띠 글자가 모두 빨강이라 글이 보이지 않았습니다. 이제 글은 상태 표시줄 글색으로 굵게 보이고, 「밖의 AI 에이전트 연결됨 · …」 으로 무슨 띠인지 알 수 있습니다. 「끊기」 단추에도 풍선 도움말이 있습니다.
- **「최근 호출」 창 글이 잘리던 문제**: 띠를 눌러 여는 창의 글이 왼쪽에서 잘리지 않습니다. 맨 위에 이 창이 무엇인지 한 줄 설명이 나옵니다.
