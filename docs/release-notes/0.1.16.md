# Oranda 0.1.16

## 새 기능

- 조회 결과에서 고른 값을 줄 단위 IN 목록으로 복사할 수 있습니다. 결과 그리드에서 `Alt+C`(macOS는 `Option+C`)를 누릅니다.
- 결과 그리드의 왼쪽 칸에 행 번호가 나옵니다. 화면 순서대로 1부터 매기고, 정렬하거나 거르면 다시 매깁니다. 행 번호는 복사되지 않습니다. 모니터, 행 보기처럼 같은 그리드를 쓰는 화면에도 함께 나옵니다.
- 편집 모드의 결과에서 셀을 고른 뒤 `Enter`를 누르면 셀 편집이 열립니다. 편집 중에 `Enter`를 누르면 값을 확정하고 같은 열의 아래 행 셀 편집으로 이어 갑니다.
- MyBatis 쿼리에 입력한 바인드 값이 저장됩니다. 시나리오가 없는 쿼리에 값을 입력하면 「자동 저장」 시나리오를 만들어 값을 저장하므로, 매퍼를 다시 열어도 값이 그대로 나옵니다.
- LLM 프로필을 「로컬 AI」로 지정할 수 있습니다. 직접 관리하는 서버의 모델이라면 **LLM 프로필 관리**에서 프로필마다 지정합니다. 지정한 프로필로 보낼 때는 값을 가리지 않으므로 AI가 실제 값을 보고 답합니다.

## 고친 것

- 줄 끝의 `/* */` 주석 뒤에 커서가 있으면 문장을 찾지 못하던 것을 고쳤습니다. 이제 실행과 AI 명령이 그 문장을 그대로 씁니다.

## 알려진 한계

- 「로컬 AI」로 지정하면 운영 접속에서도 SQL 문장의 값, 문장 안의 주석, 오류 문구, 히스토그램 끝값을 가리지 않고 보냅니다. 값 가림 설정이 켜져 있어도 가리지 않습니다.
- 비밀번호, 주민번호, 카드, 계좌, 주소, 인증값 열의 히스토그램 끝값은 「로컬 AI」에도 보내지 않습니다. 열 이름으로 판단하므로 이름에 드러나지 않는 열은 가려지지 않을 수 있습니다. SQL 문장에 직접 쓴 값은 어떤 열이든 그대로 갑니다.
- 「로컬 AI」로 지정해도 조회 결과의 행과 바인드 값은 보내지 않습니다. 문장 앞이나 뒤에 붙은 주석도 보내지 않습니다.
- Anthropic 형식 프로필은 claude 실행 파일을 거치므로, 가리지 않은 값이 그 PC의 claude 대화 기록에 남을 수 있습니다. 암호화하지 않은 HTTP 서버로 보내면 값이 암호화 없이 전달됩니다.
- 「로컬 AI」는 Windows에서 테스트 접속으로 SQL 설명과 일반 대화의 객체 구조 조회만 실제 앱으로 확인했습니다. 오류 고치기, 튜닝, 히스토그램 끝값, 운영 접속은 실제 앱으로 확인하지 않았습니다.
- MyBatis 값 저장은 이름에 pass, pwd, secret, token이 든 변수의 값과 고른 형식을 저장하지 않습니다.
- macOS에서 셀 편집을 `Enter`로 여는 동작과 한글 조합 중 `Enter`는 실제 키보드로 확인하지 않았습니다.
- macOS에서 셀을 편집하는 중에 `Option+C`가 글자 입력과 겹치는지 확인하지 않았습니다.
- 매뉴얼의 결과 그리드 그림에는 행 번호가 아직 나오지 않습니다.
