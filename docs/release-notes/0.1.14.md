# Oranda 0.1.14

## 새 기능

- 도움말 > 사용자 문서(`F1`)가 사용 설명서를 엽니다. 지금 커서가 있는 화면(SQL 편집기, 결과 그리드, PL/SQL, MyBatis, 스키마 브라우저, 모니터)에 맞는 절을 기본 브라우저로 열고, 화면을 알 수 없으면 첫 쪽을 엽니다. 설명서는 https://jongik-sv.github.io/oranda/ 에서 누구나 볼 수 있습니다. 브라우저를 열 수 없으면 아무 일도 일어나지 않으니 이 주소를 직접 여세요.
- 설정 > AI 모델 에서 목록에 없는 CLI 를 명령으로 등록할 수 있습니다. 명령 틀 목록에서 고르면 채워집니다. 일반 대화와 명령 3종(실행 계획 해설, SQL 설명, 오류 고치기)에만 쓰이고 AI 튜닝은 시작하지 않습니다. 운영처럼 내용을 가리는 접속에는 보내지 않습니다. 자동 승인 옵션이 든 명령을 등록하면 경고가 뜹니다.
- Codex CLI 와 Antigravity CLI 를 운영 접속에서도 쓸 수 있습니다. 전에는 운영 접속에서 DB 도구를 쓰는 요청을 보내지 않았습니다. 접속의 AI 허용 수준과 운영 리터럴 가림은 그대로 적용됩니다.
- AI 대화 창에서 여러 문단·목록·표·코드에 걸쳐 마우스로 끌어 글을 고르고 복사할 수 있습니다. 전에는 문단 하나 안에서만 골랐습니다. 끌다가 대화 영역 위나 아래 끝에 가까워지면 자동으로 스크롤합니다.

## 고친 것

- 업데이트 안내(상태 표시줄의 새 버전 표시)가 어두운 테마와 빨간 운영 접속 표시줄에서 묻혀 잘 보이지 않던 것을 고쳤습니다. 설정 창의 오류 문구가 흐리게 나오던 것과 입력칸 안내 글자가 흐리던 것도 함께 고쳤습니다.

## 알려진 한계

- 기타 CLI 의 가림은 환경 변수 값과 글자 그대로 같은 글만 대상입니다. 명령 인자에 직접 쓴 비밀은 가려지지 않고, 5글자 미만·`true`/`false`·숫자만인 값도 가려지지 않아 짧은 비밀이 답에 보일 수 있습니다.
- 기타 CLI 는 앱을 닫아도 실행 중인 CLI 가 바로 멈추지 않을 수 있습니다.
- 기타 CLI 목록의 「설치됨」 표시는 실행 파일이 PATH 에 있는지만 보므로 실제 실행 결과와 다를 수 있습니다.
- 가린 뒤의 대화 내용도 Codex·Antigravity 가 자기 폴더(`~/.codex`, `~/.gemini/antigravity-cli`)에 남기며 Oranda 가 지울 수 없습니다.
- opencode 는 아직 고를 수 없습니다.
