# Oranda 0.1.14

## 바뀐 것

- Codex CLI 와 Antigravity CLI 를 운영 접속에서도 쓸 수 있습니다. 전에는 운영 접속에서 DB 도구를 쓰는 요청을 보내지 않았습니다. 접속의 AI 허용 수준과 운영 리터럴 가림은 그대로 적용되며, 가린 뒤의 대화 내용도 CLI 자기 폴더(`~/.codex`, `~/.gemini/antigravity-cli`)에 남고 Oranda 가 지울 수 없습니다.
- 설정 > AI 모델 에서 목록에 없는 CLI 를 명령으로 등록할 수 있습니다(미출시). 명령 틀 목록에서 고르면 채워집니다. 일반 대화와 명령 3종에만 쓰이고, 튜닝은 시작하지 않으며, 운영처럼 내용을 가리는 접속에는 보내지 않습니다. 자동 승인 옵션이 든 명령은 경고가 뜹니다. 가림은 환경 변수 값과 글자 그대로 같은 글만 해당해 명령 인자에 직접 쓴 비밀은 가려지지 않고, 5글자 미만·`true`/`false`·숫자만인 값도 가려지지 않아 짧은 비밀이 답에 보일 수 있고, 앱을 닫아도 실행 중인 CLI 가 바로 멈추지 않을 수 있습니다. 「설치됨」 표시는 실제 실행 결과와 다를 수 있습니다.
- opencode 전용 연결을 넣었지만 아직 꺼져 있어 고를 수 없습니다. 실제 모델 왕복을 확인하지 못했습니다.
