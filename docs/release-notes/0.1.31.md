# Oranda 0.1.31

## 새 기능

- **Tibero 작업 보기**: 스키마 브라우저 「스케줄러 잡」 폴더에 Tibero 의 DBMS_JOB 과 스케줄러 잡이 보입니다.
  - DBMS_JOB 에는 「DBMS」 표가 붙어 스케줄러 잡과 구별됩니다. 이름이 없는 DBMS_JOB 은 작업 번호로 보입니다.
  - 고장 난 작업에는 BROKEN, 실패한 적이 있는 작업에는 FAILED 표식이 붙습니다.
  - 작업을 고르면 다음 실행, 실행 간격, 실행 내용, 실패 수, 마지막 실행이 보입니다. DBMS_JOB 은 DDL 탭에서 다시 만드는 스크립트(`DBMS_JOB.SUBMIT`)를 보여 줍니다.
  - Tibero 는 DBMS_JOB 을 접속한 계정 자신의 것만 보여 줍니다.

## 고친 점

- **Tibero 원격 동의어가 깨진 것으로 보이던 문제**: DB 링크를 거치는 동의어에 주황 깨짐 표식 대신 원격 표식이 붙습니다. 동의어 DDL 도 `FOR "소유자"."이름"@링크` 로 바르게 나옵니다.
