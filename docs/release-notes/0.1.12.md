# Oranda 0.1.12

## 바뀐 것

- AI 튜닝과 대화가 쓸 모델을 「LLM 프로필」 로 고를 수 있습니다. 설정 > AI 모델 에서 「선택 안 함」 또는 「직접 선택」 을 고르고, 프로필 드롭다운과 「프로필 관리」 창에서 프로필을 만들고 고치고 지웁니다. 연결 테스트와 모델 새로고침도 이 창에 있습니다. 프리셋은 Anthropic, Z.AI, Google Gemini, OpenAI, Ollama, LM Studio, 직접 입력입니다.
  - Anthropic 형식 프로필(Anthropic, Z.AI, 직접 입력)은 PC 의 `claude` 실행 파일로, OpenAI 형식 프로필(OpenAI, Gemini, Ollama, LM Studio, 직접 입력)은 Oranda 가 직접 연결해서 씁니다. OpenAI 형식에는 `claude` 가 필요 없습니다.
  - 어느 경로든 DB 도구 호출은 기존과 같은 허용 수준·범위 검사·리터럴 가림·감사 기록을 지납니다. API 키는 Windows 는 DPAPI, macOS 는 키체인에 저장하며 설정 파일에는 쓰지 않습니다.
  - 프로필 경로는 프록시를 거치지 않고 입력한 주소로 직접 연결합니다. OpenAI 형식 프로필의 실행과 연결 테스트·모델 새로고침은 HTTP 리다이렉트를 따르지 않습니다(Anthropic 형식 프로필의 실행은 `claude` 실행 파일이 연결하므로 Oranda 가 정하지 않습니다). Claude Code(구독) 경로는 그대로입니다. 기존 설정은 그대로 Claude Code 로 동작합니다.
- AI 대화 입력에 이미지를 붙일 수 있습니다. 붙여 넣기, 끌어 놓기, 파일 선택을 쓰며 한 번에 5장, PNG·JPEG·WebP·GIF 입니다. 큰 이미지는 줄이고 장당 5 MB 를 넘으면 JPEG 로 다시 인코딩합니다. 이미지 안의 값은 가릴 수 없으므로, 리터럴을 가리는 대화(운영 접속 포함)에서는 새 이미지를 보낼 때마다 받는 곳을 적은 확인 창이 뜹니다.
- AI 대화 창을 튜닝을 시작하지 않고도 처음부터 쓸 수 있습니다. 활성 문서가 지금 접속의 SQL 탭이면 그 탭의 현재 문장 범위에서 DB 도구를 엽니다. 활성 문서가 SQL 탭이 아니거나 다른 접속의 탭이면 문장과 도구를 닫고 도구 없이 답합니다. 리터럴을 가리는 대화(운영 접속 포함)에서는 입력한 글이 가려지지 않는다는 확인을 대화당 한 번 받습니다.
- AI 튜닝 결과를 Markdown 또는 HTML 레포트로 저장할 수 있습니다. 가린 대화는 가려서 보낸 자리표시를 되돌리지 않고, 인덱스 후보는 제안만 담으며, 파일 이름에 SQL 을 넣지 않습니다.
- 실행 계획 창이 SQL 탭마다 자기 계획을 보여 줍니다. 탭의 실제 계획은 그 탭의 마지막 실행과 세션의 실행 순번이 맞을 때만 읽고(이 앱의 실행 기록이 없는 세션은 전처럼 읽습니다), 맞지 않으면 이유를 안내합니다.
- 「실행하고 실제 계획(A-Rows)」 을 더했습니다(`Ctrl+Alt+Shift+E`, macOS `Cmd+Option+Shift+E`). 툴바, 튜닝 메뉴, 계획 창 단추에서도 부릅니다. 일반 실행(`Ctrl+Enter`)과 같은 규칙(선택 영역, 빈 줄 구분은 「빈 줄로 문장 나누기」 를 켠 때만, 선택 영역에 문장이 여러 개면 실행하지 않고 안내)으로 고른 문장을 힌트를 넣은 사본으로 실행해 모든 행을 읽고 A-Rows 가 있는 실제 계획을 엽니다. 조회(SELECT)만 실행하며 `FOR UPDATE`, DML, WITH 뒤에 오는 DML 은 거부합니다. 받은 계획이 실행한 글과 다르면 열지 않습니다. 메뉴의 「실제 행 수 받으며 다시 실행」도 같은 접속·세션 확인을 거칩니다.

## 알려진 한계

- 실서버로 확인하지 못한 프로필: Anthropic API, Z.AI, Google Gemini, OpenAI, LM Studio. 키·서버가 없어 가짜 서버 시험으로만 확인했습니다. 연결이 안 되면 「연결 테스트」 의 오류를 알려 주세요.
- 프로필 경로가 프록시를 거치지 않으므로, 프록시로만 외부에 나갈 수 있는 환경에서는 클라우드 프로필(Anthropic, Z.AI, Gemini, OpenAI)이 연결되지 않습니다.
- Anthropic 형식 프로필은 Claude Code 의 managed-settings 가 `env` 를 덮어쓰는 환경에서 Oranda 가 넣은 환경 변수가 적용되지 않을 수 있습니다.
- CLI 경로에서는 claude 자체 세션 파일에 보낸 이미지가 남습니다.
- 앱을 다시 시작하면 OpenAI 형식 프로필의 이어 말하기 대화는 사라집니다.
