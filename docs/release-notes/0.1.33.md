# Oranda 0.1.33

## 새 기능

- **AI 설정을 한곳에서**: 도구 > **AI 설정…** 하나로 설정 창의 「AI」 탭이 열립니다. 예전 「AI 연결 도우미…」·「외부 에이전트 연결…」 메뉴와 「AI 모델」 탭이 여기로 모였습니다.
  - 1 「AI 가 볼 수 있는 접속」: 접속마다 AI 가 어디까지 볼지 정합니다. 2 와 3 이 모두 이 표를 따릅니다.
  - 2 「Oranda 안의 AI」: 연결 상태, 「연결 시험」, 「다시 연결 (도우미)」, 고급 설정(모델·프로필·기타 CLI·값 가림)이 있습니다.
  - 3 「밖의 AI 에이전트」: 터미널의 Claude Code·Codex·Antigravity 연결과 스킬 설치가 있습니다.
  - 탭 곳곳에 무엇을 정하는지, 단추가 무엇을 하는지 쉬운 설명을 넣었습니다.
  - AI 연결 도우미는 설정 창 위 가운데에 뜹니다. 닫으면 탭이 바뀐 값을 바로 보여 줍니다.
  - 「연결 시험」 을 Codex·Antigravity·기타 CLI 에서도 할 수 있습니다.
  - 「고급 설정」 에서 저장하지 않은 변경이 도우미 때문에 버려질 때는 먼저 묻습니다.
- **운영 접속도 「조회+행 값」**: 학습에 쓰지 않는 기업용 AI 라면 운영 접속도 「조회+행 값」 까지 올릴 수 있습니다.
  - 처음 값은 지금처럼 「조회 실행」 입니다. 올릴 때 접속 이름을 한 번 더 입력합니다.
  - 고르면 「운영 데이터 값이 AI 업체로 갑니다」 경고가 나옵니다. 회사 정보보호 규정에 맞는지 먼저 확인하세요.
- **민감 데이터 가리기 켬·끔**: 「AI 가 볼 수 있는 접속」 의 모든 접속에 「민감 데이터 가리기」 확인란이 있습니다.
  - 처음에는 켜져 있어 전화·이메일·이름 같은 값을 가립니다.
  - 끄면 그런 값도 AI 로 갑니다. 비밀번호·주민번호·카드·계좌·주소·인증값은 언제나 가립니다.
- **외부 에이전트가 바인드 변수 값을 넣습니다**: `orandactl tab binds set --binds-json` 으로 탭의 바인드 목록에 값을 넣고, `tab run --binds-json` 으로 넣고 바로 실행합니다.
  - 넣은 값은 탭의 바인드 목록에 그대로 보입니다.
  - 날짜처럼 형식이 필요한 값은 `{"value":"20261122","type":"date"}` 처럼 형식을 함께 보낼 수 있습니다.
  - 형식이 맞지 않거나 없는 이름이면 아무 값도 바꾸지 않고 거부합니다.
  - 새 안내를 쓰려면 「스킬 설치…」 를 다시 누르세요.

## 바뀐 점

- 외부 에이전트 연결 창의 「조회 허용」 확인란이 없어졌습니다. 수준은 「AI 가 볼 수 있는 접속」 표에서 바꿉니다.
- 운영 접속에서 외부 에이전트가 넣은 바인드 값은 감사 기록에 이름과 형식만 남습니다.
- 탭 글을 읽을 권한이 없는 외부 에이전트는 바인드 값을 넣을 수 없습니다.
- 「로컬 AI」 프로필을 쓰면 운영 접속의 「조회 실행」 에서도 결과 값까지 본다는 것을 화면에 알려 줍니다.

## 바로잡음

- 0.1.32 노트의 「운영 접속은 기본으로 메타데이터만 쓰고, 조회까지 열려면 따로 켜야 합니다」 는 틀린 설명이었습니다. 외부 에이전트도 운영 접속을 「조회 실행」 으로 쓸 수 있고, 연결할 때 접속 이름을 다시 입력해야 고를 수 있습니다. SELECT 를 돌려도 회사 밖 AI 에는 행 수만 갑니다.
