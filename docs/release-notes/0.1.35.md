# Oranda 0.1.35

## 고친 점

- **PL/SQL 컴파일이 시작되지 않고, 끄면 멈추던 문제**: 컴파일 전에 「다른 세션이 이 객체를 쓰는지」 확인하는 질의가 공유 풀이 큰 서버에서 한 번에 십수 분 걸렸습니다. 그동안 컴파일은 시작되지 않았고, 앱을 끄면 그 질의를 기다리며 멈췄습니다.
  - 이제 세션 목록(`V$SESSION`)으로 확인해 1초 안에 끝납니다.
  - 확인이 5초 안에 끝나지 않거나 권한이 없으면 「다른 세션의 사용 여부를 확인할 수 없습니다」 안내만 띄우고 컴파일합니다.
- **컴파일을 취소할 수 있습니다**: PL/SQL 편집기에 「컴파일 취소」 단추가 생겼습니다. 컴파일 중에 탭을 닫아도 취소됩니다. 컴파일하는 동안은 그 세션이 실행 중으로 보입니다.
- **컴파일 대기 상한**: 다른 세션이 실행 중인 프로시저를 컴파일하면 Oracle 은 그 실행이 끝날 때까지 기다립니다. 이제 정한 시간이 지나면 멈추고 「시간 초과」 로 알립니다.
  - 상한은 설정 > 실행 의 「PL/SQL 컴파일 대기(초)」 입니다. 처음 값은 60초, 0 은 상한 없음입니다.
- **컴파일을 막는 세션을 보여 줍니다**: 컴파일이 3초 넘게 끝나지 않으면 막고 있는 세션(SID·사용자·프로그램·머신)을 띠에 보입니다. `V$SESSION` 과 `DBA_OBJECTS` 를 읽을 권한(`SELECT_CATALOG_ROLE` 등)이 필요합니다.
- **취소에 서버가 답하지 않을 때**: 방화벽이나 포트 중계 때문에 취소가 서버에 닿지 않으면, 5초 뒤 그 연결을 끊고 다시 접속하라고 알립니다. 앱이 멈춘 채로 남지 않습니다.
- **앱 종료·접속 끊기가 멈추던 문제**: 실행 중인 명령이 있으면 먼저 「실행 중인 작업을 취소하고 닫을까요?」 를 묻습니다. 닫을 때의 커밋·롤백은 10초까지만 기다립니다.
- **컴파일 결과를 정직하게 알립니다**: 오류 목록을 읽지 못했으면 「컴파일됨」 이 아니라 「컴파일됐지만 오류 목록을 읽지 못했습니다」 로 알립니다. 머리글에 소유자가 없으면 세션의 현재 스키마에 컴파일하고, 소유자가 로그인 계정과 다르면 필요한 권한을 안내합니다.
- **권한이 적은 계정의 DB 정보**: `V$` 뷰를 읽을 수 없는 계정도 DB 정보 창에서 권한 없이 볼 수 있는 값(버전·세션 NLS 등)을 보고, 볼 수 없는 칸에는 필요한 권한을 알려 줍니다.
