# Oranda 0.1.36

## 고친 점

- **바인드 변수 목록이 비어 있던 문제**: 외부 에이전트가 연 SQL 탭이나 접속을 새로 정한 탭은 실행하기 전까지 「바인드 변수」 창에 `:변수` 가 보이지 않았습니다.
  - 이제 탭에 접속을 정할 때와 에이전트가 탭에 글을 넣을 때, 문장의 `:변수` 이름이 빈 줄로 목록에 들어갑니다. 이미 있던 줄의 값과 자료형은 그대로입니다.
  - 미리 들어간 줄은 값을 넣기 전까지 「값 없음」입니다. 처음 실행하면 그 변수에서 한 번 멈춥니다. 그대로 다시 실행하면 NULL 로 실행됩니다.
- **AI 조회가 ROLLUP 을 거부하던 문제**: 외부 에이전트의 조회(`orandactl query`)가 `GROUP BY ROLLUP(...)` 을 사용자 함수 호출로 보고 실행하지 않았습니다.
  - 이제 `GROUP BY` 의 `ROLLUP`·`CUBE`·`GROUPING SETS` 와 `GROUPING_ID`·`GROUP_ID` 함수를 내장 구문으로 봅니다.
