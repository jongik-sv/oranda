# Oranda 0.1.29

## 새 기능

- **스키마 브라우저에서 객체 종류를 바로 구분**: 같은 아이콘으로만 보이던 객체에 세부 종류와 상태가 보입니다.
  - 이름 오른쪽에 글자 표식이 붙습니다. 예: `GTT·T`(임시, 트랜잭션), `GTT·S`(임시, 세션), `PART`(파티션), `IOT`, `EXT`(외부), `BEF`(BEFORE 트리거), `→TAB`(테이블을 가리키는 동의어), `PK`, `UQ`
  - 아이콘은 그 종류 색으로 칠해지고, 오른쪽 아래에 종류 도형이 붙습니다. 마우스를 올리면 풀어 쓴 이름이 나옵니다.
  - 대상: 테이블(임시·파티션·IOT·클러스터·외부·객체 테이블), 트리거, 작업, 동의어, 구체화 뷰, 타입, 그리고 테이블을 펼쳤을 때의 열·인덱스·제약
  - 쓸 수 없는 상태(UNUSABLE 인덱스, 대상이 없는 동의어, STALE 구체화 뷰, 실패한 작업)는 주황으로, 꺼진 트리거·제약·작업은 흐리게 보입니다.
  - 목록은 지금처럼 먼저 나오고 표식은 잠시 뒤에 붙습니다. 표식을 읽지 못해도 목록과 화면은 막히지 않습니다.
  - Tibero 에는 클러스터가 없고 객체 테이블·작업·동의어의 DB 링크 대상을 알려 주는 사전 정보가 없어, 이것들은 표시하지 않습니다.
- **MyBatis 문서에서 「튜닝 > AI 튜닝」**: MyBatis 작업 공간에서도 메뉴가 보이고, 시작 창 제목이 「AI 튜닝 — 펼친 SQL」로 나옵니다.

## 고친 점

- **서버가 결과를 보내다 멈출 때 끝없이 기다리던 문제**: Oracle·Tibero 에서 목록이나 결과를 받는 도중 30초 동안 한 행도 오지 않으면 기다림을 끊고, 그 연결은 끊긴 것으로 처리합니다. 스키마 브라우저에는 「서버 응답이 없어 목록을 읽지 못했습니다. … 「세션 새로 고침」으로 다시 접속한 뒤 새로 고침하세요.」가 나옵니다. 행이 계속 오는 큰 목록은 끊지 않습니다.
- **도구 창이 문서 탭 줄에 섞여 화면이 깨지던 문제**: 도구 창(스키마 브라우저 등)을 제목 줄로 끌어 문서 영역에 놓을 수 없게 했습니다. 이미 섞여 저장된 배치는 다음에 열 때 제자리로 돌아갑니다.
- **행 보기에 번호가 두 번 나오던 문제**: 「#」 열을 없애고 맨 앞 행 번호만 남겼습니다.
- **오류 고치기 막대**: SQL·PL/SQL 오류 고치기도 다른 AI 띠처럼 보내기 전에 받는 곳과 보낼 정보를 확인합니다.
