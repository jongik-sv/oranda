# Oranda 0.1.11

## 바뀐 것

- 업데이트 알림을 눈에 띄게 했습니다. 시작할 때마다(5초 뒤) 새 버전을 확인하고, 실행 중에도 1시간마다 확인합니다. 새 버전을 찾거나 내려받기를 마치면 주 창 위쪽에 「Oranda {버전} 이 준비되었습니다」 띠가 뜨고, 「다시 시작해 적용」·「자세히」·「나중에」 를 고를 수 있습니다. 「나중에」 로 닫은 버전은 그 실행에서 다시 알리지 않습니다. 설정의 「시작할 때와 실행 중에 업데이트 확인」 을 끄면 둘 다 하지 않습니다.
- AI 튜닝의 재작성 제안을 「적용」 하면 원래 탭은 그대로 두고 「원래 탭 이름 (튜닝)」 새 SQL 탭에 넣습니다. 새 탭은 원래 탭과 같은 접속으로 열리고, 앞뒤 다른 문장·주석은 그대로입니다. 같은 대화에서 다시 적용하면 열려 있는 그 탭의 글만 바꿉니다.
