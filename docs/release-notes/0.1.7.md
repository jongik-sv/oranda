# Oranda 0.1.7

## 고친 것

- Java(JVM)가 있는 서버에서 Java 클래스 상세의 메서드·필드 형식이 「-」·「-[]」 로 보이던 것(예 `hi(java.lang.String, -[])`)을 `hi(java.lang.String, int[])`·`void`·`int` 처럼 고쳤고, 「소스 열기」가 그 클래스를 만든 Java 소스를 찾지 못하던 것과 Java 소스 상세의 「Java 클래스」 표가 비던 것을 고쳤습니다. Java 컴파일 오류는 javac 출력 한 줄씩 1줄 1열로 흩어져 보이던 것을 오류 하나에 한 줄(실제 줄·열, `cannot find symbol (symbol: variable missing; …)`)로 묶어 보이며, 이름이 128자를 넘는 Java 소스도 편집기에서 실행한 뒤 오류를 찾고, 정상 컴파일에 남는 `Note:` 줄은 경고로 보입니다.
