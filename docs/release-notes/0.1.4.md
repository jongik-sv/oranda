# Oranda 0.1.4

## 새 기능

- 튜닝할 SQL 을 추천합니다(규칙 기반, 외부 서비스 없음). 튜닝 메뉴 「튜닝 추천」 또는 SQL 모니터 아래 「튜닝 추천」 탭에서 「새로 고침」을 누르면 공유 풀(v$sqlstats) 상위 SQL 을 실행당 경과·전체 경과 비중·실행당 읽기·행당 읽기·물리 읽기·큰 표 전체 스캔·카티션 조인·자식 커서·리터럴 반복(바인드 변수 권장)·실행마다 파싱·대기 비중 규칙으로 살펴 점수순으로 보입니다. 줄을 고르면 이유와 근거 수치·SQL 전문이 보이고, 「튜닝 도우미로 열기」·「자식 커서」·「편집기로 열기」로 이어집니다. SYS 같은 내부 스키마는 기본으로 빼고(끌 수 있음), 서버 부하를 줄이려고 자동 새로 고침은 하지 않습니다. 세션 모니터의 「튜닝 추천」 탭은 지금 활성 세션이 실행 중인 SQL 을 같은 규칙으로 검사하고 「SQL 모니터의 튜닝 추천에서 보기」로 넘어갑니다.

## 고친 것

- 업데이트 확인이 「업데이트를 확인하지 못했습니다: … 403 (rate limit exceeded)」 로 실패하던 문제를 고쳤습니다. 이제 GitHub 요청 한도를 쓰지 않는 릴리스 다운로드 주소로 확인하고, 실패하면 「요청 한도 초과」·「파일을 찾지 못함」·「서버에 닿지 않음」 처럼 이유를 알려 줍니다(원문은 마우스를 올리면 보입니다). 설정 > 업데이트의 서버 주소 칸에 `https://github.com/<소유자>/<저장소>/releases/latest/download` 같은 릴리스 주소도 넣을 수 있습니다. 0.1.2·0.1.3 에서는 요청 한도가 풀린 뒤 확인하거나 0.1.4 설치 파일(Setup.exe)을 직접 받아 설치하세요.
- 앱 아이콘(창·작업 표시줄·설치 파일)의 「O」 둘레와 가운데 구멍이 검은 배경으로 보이던 문제를 고쳤습니다. 이제 배경이 투명해서 밝은 화면·어두운 화면 어디서나 「O」 만 보입니다.
- 실행 이력에서 줄을 고르면 아래에 나오는 문장 상자의 높이를 바꿀 수 없던 문제를 고쳤습니다. 목록과 상자 사이 분할선을 끌어 높이를 바꾸고, 바꾼 높이는 앱을 켜 둔 동안 이어집니다. 긴 문장은 상자 안에서 스크롤합니다.
- 튜닝 도우미의 「재작성 후보」·「힌트 대안」 에서 체크 상자가 흐려 왜 벤치마크에 넣을 수 없는지 알 수 없던 문제를 고쳤습니다. 바꾼 SQL 이 없는 규칙은 「경고만」 과 까닭(예: 「바꿔도 성능 같음 — 필요한 열만 고르세요」), 쓸 수 없는 힌트는 「—」 로 보이고, 체크 칸은 칸 어디를 눌러도 바뀝니다. 또 문자 열에 숫자를 비교한 조건(열 = 123 → 열 = '123', 결과가 달라질 수 있어 체크는 꺼 둠), TO_CHAR(날짜 열, 'YYYYMMDD') = '…'(→ 날짜 범위), SUBSTR(열, 1, n) = '…'(→ LIKE '…%') 은 이제 바꾼 SQL 을 만들어 벤치마크할 수 있습니다.
- macOS 앱 아이콘(Dock·Finder·설치 파일)의 둥근 사각형 바깥에 흐린 사무실 사진 배경이 그대로 보이던 문제를 고쳤습니다. 이제 둥근 사각형 바깥이 투명해서 금붕어 아이콘만 보입니다.

## 바뀐 것

- 템플릿·바인드 변수 같은 오른쪽 도구 창이 SQL 편집기 옆(결과 영역 위)까지만 붙던 것을, 편집기 위끝부터 아래 결과 영역 아래끝까지 오른쪽 세로 전체를 쓰게 바꿨습니다. 닫으면 편집기·결과가 다시 전체 폭을 씁니다. 저장된 배치도 처음 한 번 이 모양으로 옮겨집니다.
- 세션 모니터와 SQL 모니터의 목록이 조회 결과와 같은 그리드가 됐습니다. 머리글을 눌러 정렬(오름 → 내림 → 해제, 숫자는 수 크기로)하고, 머리글을 끌어 열 순서를 바꾸고, 경계를 끌어 너비를 맞추고, 머리글 ▾ 로 열 값을 거를 수 있습니다. 자동 새로 고침이나 다시 검색을 해도 정렬·열 순서·너비·필터·고른 세션(또는 SQL)·스크롤 위치가 그대로 남습니다. 세션 모니터의 「경과」 열은 「경과(초)」 숫자 열로 바뀌었습니다.
- 행 보기(오른쪽 도구 창)의 필드 목록이 조회 결과와 같은 그리드(번호·열 이름·타입·값)가 됐습니다. 머리글 정렬·열 끌기·너비·▾ 열 필터·칸 범위 복사(Ctrl+Shift+C 는 머리글 포함)가 되고, 결과 그리드에서 다른 행으로 옮겨도 정렬·열 순서·너비·필터·고른 칸·스크롤이 그대로 남습니다. 편집 모드에서는 값 칸을 두 번 누르거나 F2·Enter 로 표 아래 입력칸에서 고치고, LOB 처럼 고칠 수 없는 값은 두 번 누르면 값 보기 창이 열립니다.
