# Oranda 0.1.4

## 고친 것

- 업데이트 확인이 「업데이트를 확인하지 못했습니다: … 403 (rate limit exceeded)」 로 실패하던 문제를 고쳤습니다. 이제 GitHub 요청 한도를 쓰지 않는 릴리스 다운로드 주소로 확인하고, 실패하면 「요청 한도 초과」·「파일을 찾지 못함」·「서버에 닿지 않음」 처럼 이유를 알려 줍니다(원문은 마우스를 올리면 보입니다). 설정 > 업데이트의 서버 주소 칸에 `https://github.com/<소유자>/<저장소>/releases/latest/download` 같은 릴리스 주소도 넣을 수 있습니다. 0.1.2·0.1.3 에서는 요청 한도가 풀린 뒤 확인하거나 0.1.4 설치 파일(Setup.exe)을 직접 받아 설치하세요.
- 앱 아이콘(창·작업 표시줄·설치 파일)의 「O」 둘레와 가운데 구멍이 검은 배경으로 보이던 문제를 고쳤습니다. 이제 배경이 투명해서 밝은 화면·어두운 화면 어디서나 「O」 만 보입니다.
- 실행 이력에서 줄을 고르면 아래에 나오는 문장 상자의 높이를 바꿀 수 없던 문제를 고쳤습니다. 목록과 상자 사이 분할선을 끌어 높이를 바꾸고, 바꾼 높이는 앱을 켜 둔 동안 이어집니다. 긴 문장은 상자 안에서 스크롤합니다.

## 바뀐 것

- 템플릿·바인드 변수 같은 오른쪽 도구 창이 SQL 편집기 옆(결과 영역 위)까지만 붙던 것을, 편집기 위끝부터 아래 결과 영역 아래끝까지 오른쪽 세로 전체를 쓰게 바꿨습니다. 닫으면 편집기·결과가 다시 전체 폭을 씁니다. 저장된 배치도 처음 한 번 이 모양으로 옮겨집니다.
- 세션 모니터와 SQL 모니터의 목록이 조회 결과와 같은 그리드가 됐습니다. 머리글을 눌러 정렬(오름 → 내림 → 해제, 숫자는 수 크기로)하고, 머리글을 끌어 열 순서를 바꾸고, 경계를 끌어 너비를 맞추고, 머리글 ▾ 로 열 값을 거를 수 있습니다. 자동 새로 고침이나 다시 검색을 해도 정렬·열 순서·너비·필터·고른 세션(또는 SQL)·스크롤 위치가 그대로 남습니다. 세션 모니터의 「경과」 열은 「경과(초)」 숫자 열로 바뀌었습니다.
