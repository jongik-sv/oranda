# Oranda 0.1.4

## 고친 것

- 업데이트 확인이 「업데이트를 확인하지 못했습니다: … 403 (rate limit exceeded)」 로 실패하던 문제를 고쳤습니다. 이제 GitHub 요청 한도를 쓰지 않는 릴리스 다운로드 주소로 확인하고, 실패하면 「요청 한도 초과」·「파일을 찾지 못함」·「서버에 닿지 않음」 처럼 이유를 알려 줍니다(원문은 마우스를 올리면 보입니다). 설정 > 업데이트의 서버 주소 칸에 `https://github.com/<소유자>/<저장소>/releases/latest/download` 같은 릴리스 주소도 넣을 수 있습니다. 0.1.2·0.1.3 에서는 요청 한도가 풀린 뒤 확인하거나 0.1.4 설치 파일(Setup.exe)을 직접 받아 설치하세요.
- 앱 아이콘(창·작업 표시줄·설치 파일)의 「O」 둘레와 가운데 구멍이 검은 배경으로 보이던 문제를 고쳤습니다. 이제 배경이 투명해서 밝은 화면·어두운 화면 어디서나 「O」 만 보입니다.
