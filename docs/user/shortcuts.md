# 단축키

`Primary` 는 Windows 의 `Ctrl`, macOS 의 `Cmd` 다. 전체 목록과 바꾸는 법은 도움말 > 단축키 목록, 정본은 `docs/design/keymaps/default.json` 이다.

| 동작 | 키 |
|---|---|
| 새 SQL 편집기 | Primary+N |
| 새 PL/SQL 편집기 | Primary+Shift+N |
| 열기 / 저장 / 모두 저장 | Primary+O / S / Shift+S |
| 탭 닫기 / 닫은 탭 다시 열기 | Primary+W / Shift+T |
| 접속 관리 | Primary+Shift+O |
| 찾기 / 다음 찾기 | Primary+F / F3 |
| DB 객체로 이동 / 스키마 브라우저에서 찾기 | Primary+P / Alt+F1 (macOS Option+F1) |
| 결과 그리드: 외래키로 부모 행 열기 / 이 행을 참조하는 행 열기 | F4 / Shift+F4 |
| 결과 그리드: Excel 로 내보내기 | Primary+Alt+E (macOS Cmd+Option+E) |
| 사용자 문서 | F1 |

다른 프로그램에 익숙하면 설정 > 키맵 에서 Orange5·PL/SQL Developer·SQL Developer 프리셋을 고를 수 있다.
