# AI 튜닝과 대화

설정 > AI 모델 에서 쓸 모델을 고른다. 「선택 안 함」 이면 AI 기능을 쓰지 않는다. 「직접 선택」 에서는 아래 중 하나를 고른다.

| 종류 | 필요한 것 |
|---|---|
| Claude Code | 이 PC 에 로그인된 `claude`. 키·주소가 필요 없다 |
| 내 프로필 (Anthropic 형식: Anthropic, Z.AI, 직접 입력) | `claude` 실행 파일, 주소, 모델, 필요하면 API 키 |
| 내 프로필 (OpenAI 형식: OpenAI, Google Gemini, Ollama, LM Studio, 직접 입력) | 주소, 모델, 필요하면 API 키. `claude` 는 필요 없다 |

## 프로필 만들기

1. 설정 > AI 모델 > 「프로필 관리」 (또는 드롭다운의 「새 프로필 만들기」).
2. 프리셋 카드를 고르고 주소·API 키·모델·최대 입력/출력 토큰·프로필 이름을 넣는다. 「모델 새로고침」 으로 서버의 모델 목록을 받는다.
3. 「연결 테스트」 로 확인한 뒤 「프로필 저장」. 저장은 설정 창의 확인과 별개로 바로 기록된다.

- API 키는 Windows 는 DPAPI, macOS 는 키체인에 저장되고 설정 파일에는 쓰이지 않는다. 프로필을 지우면 키도 지운다. 쓰고 있던 프로필을 지우면 Claude Code 로 되돌아간다.
- 주소가 `http://` 이고 localhost 가 아니면 SQL 과 이미지가 암호화 없이 전달된다는 안내가 뜬다.
- 프로필 경로는 프록시 설정을 따르지 않고 입력한 주소로 직접 연결한다. OpenAI 형식 프로필의 실행과 연결 테스트·모델 새로고침은 HTTP 리다이렉트도 따르지 않는다(Anthropic 형식 프로필의 실행은 `claude` 실행 파일이 연결하므로 Oranda 가 정하지 않는다). 프록시로만 외부에 나갈 수 있는 PC 에서는 클라우드 프로필이 연결되지 않을 수 있다. Claude Code 경로는 예전과 같다.
- 모델이나 주소를 바꾸면 앞 대화는 이어 말할 수 없다. 새 대화로 시작한다.

## 일반 대화

AI 대화 창은 튜닝을 시작하지 않아도 처음부터 쓸 수 있다. 활성 문서가 지금 접속의 SQL 탭이고 커서 아래에 문장이 있으면 그 문장 범위에서 DB 도구를 쓴다. 활성 문서가 SQL 탭이 아니거나(PL/SQL 편집기, 객체 상세) 다른 접속의 탭이면 문장과 DB 도구를 쓰지 않고 답한다. 접속의 AI 허용 수준이 「끔」 이면 DB 도구를 쓰지 않는다. 도구를 쓸 때는 그 문장도 함께 보낸다(가리는 대화는 값을 가려서). 「새 대화」 단추로 처음부터 다시 시작한다.

운영 접속이거나 설정에서 리터럴 가림을 켠 대화는 SQL 문장과 도구 결과의 값만 가린다. 입력한 글과 이미지는 가려지지 않으므로, 글은 대화당 한 번, 이미지는 새로 보낼 때마다 확인 창을 거친다.

## 이미지 첨부

대화 입력칸에 붙여 넣기(`Primary+V`), 끌어 놓기, 파일 선택으로 이미지를 붙인다. 한 번에 5장, PNG·JPEG·WebP·GIF 이며 큰 이미지는 줄여서 보낸다. 프로필이 이미지를 지원하지 않는다고 표시돼 있으면 첨부할 수 없다. 이미지 안의 값은 가려지지 않는다.

## 레포트와 계획

- 튜닝이 끝나면 대화 창에서 결과를 Markdown 이나 HTML 레포트로 저장할 수 있다. 가린 대화는 가려서 보낸 자리표시(`:v1` 등)가 그대로 남는다.
- 실행 계획 창은 SQL 탭마다 자기 계획을 보여 준다.
- 「실행하고 실제 계획(A-Rows)」(`Primary+Alt+Shift+E`, 툴바·튜닝 메뉴·계획 창 단추): 일반 실행(`Primary+Enter`)과 같이 선택 영역이 있으면 그 글을, 없으면 커서 아래 문장을(「빈 줄로 문장 나누기」 를 켠 때만 빈 줄로도 나눈다. 선택 영역에 문장이 여러 개면 실행하지 않고 안내한다) 힌트를 넣은 사본으로 실행해 모든 행을 읽고 A-Rows 가 있는 실제 계획을 연다. 조회(SELECT)만 되고 `FOR UPDATE`, DML, WITH 뒤에 오는 DML 은 거부된다. 받은 계획이 실행한 글과 다르면 열지 않는다. 편집기 글은 바뀌지 않는다.
