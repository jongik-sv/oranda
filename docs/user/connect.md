# 접속

접속 방법은 사용 설명서로 옮겼습니다. 원본은 사이트 한 곳에만 둡니다.

- [첫 접속](https://jongik-sv.github.io/oranda/connect/first-connection/): 접속을 만들고 데이터베이스에 연결하는 과정, 비밀번호 저장 위치
- [접속 관리](https://jongik-sv.github.io/oranda/connect/manage/): 접속 목록 정리, 가져오기와 내보내기, 운영 접속 보호 표시, 비밀번호 변경

앱에서는 도움말 메뉴의 「사용 설명서」나 `F1` 키로 같은 쪽을 엽니다.
