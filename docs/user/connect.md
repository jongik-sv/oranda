# 접속

1. 파일 > 접속 관리(`Ctrl+Shift+O`, macOS `Cmd+Shift+O`)를 연다.
2. 「새 접속」에서 이름, 호스트, 포트, 서비스 이름, 사용자를 넣는다.
3. 비밀번호는 Windows 는 DPAPI, macOS 는 키체인에 저장된다. 설정 파일에는 쓰이지 않는다.
4. 「테스트」로 확인한 뒤 「접속」을 누른다.

| 증상 | 확인 |
|---|---|
| 서버에 닿지 않음 | 호스트·포트·방화벽 |
| ORA-12514 | 서비스 이름 |
| 지원하지 않는 서버 버전 | 지원 범위는 도움말 > 정보 |
