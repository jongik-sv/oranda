# Tibero 사용 안내 (사내 배포용)

이 쪽은 Tibero 에 접속하려는 사용자를 위한 안내입니다. 공개 사용 설명서와 공개 릴리스 노트에는 싣지 않습니다(결정 D-046·25).

## 지원 범위

- 대상 서버: Tibero 6 이상. 시험은 6.2.15 로만 했고 Tibero 7 은 서버가 없어 확인하지 못했습니다.
- 접속·SQL 실행·취소·결과·DBMS_OUTPUT 을 쓸 수 있습니다. 스키마 브라우저·실행 계획·모니터·튜닝은 단계적으로 열립니다.
- 아직 만들지 않은 영역의 메뉴는 숨기지 않고 회색으로 두며, 마우스를 올리면 「Tibero 에서는 아직 지원하지 않음」 이유가 보입니다.
- Tibero 에 없는 기능(SQL 모니터 보고서·AWR·ASH·세션 트레이스·TKPROF·옵티마이저 트레이스·Java 소스)은 「Tibero 에서는 지원하지 않음」으로 보입니다.
- TLS·지갑·Autonomous 접속은 Oracle 전용입니다.
- 상태 표시줄에는 서버가 `Tibero 6.2` 처럼 보이고, 오류는 `TBR-nnnn` 번호로 나옵니다.

## 드라이버 받기와 지정

Tibero 드라이버(TDP.NET Core, `Tibero.DataAccess.dll`)는 TmaxTibero 라이선스라 앱에 들어 있지 않습니다. tibero.com 기술지원에서 TDP.NET Core(1.1.x, 확인된 버전 1.1.35)를 받으세요.

1. 받은 `.nupkg` 를 풀거나 그대로 둡니다. 압축을 풀었다면 `lib/net5.0/Tibero.DataAccess.dll` 이 드라이버입니다.
2. 설정 > 「드라이버」 탭(또는 명령 팔레트의 「Tibero 드라이버 지정…」)을 엽니다.
3. 칸에 dll 파일·dll 이 든 폴더·`.nupkg` 중 하나의 경로를 적거나 [찾아보기…]·[폴더…]로 고릅니다.
4. [확인]을 눌러 상태 줄을 봅니다.
   - 「Tibero.DataAccess 1.1.35 — 사용 가능」: 쓸 수 있습니다.
   - 「시험하지 않은 버전이지만 사용할 수 있음」: 1.x 의 다른 버전입니다. 동작은 하지만 확인된 버전이 아닙니다.
   - 「.NET Framework 용 TDP.NET(2.x)은 쓸 수 없음」: TDP.NET Core 1.1.x 가 필요합니다.
   - 「Tibero 드라이버가 아님」·「파일 없음」: 경로를 다시 확인하세요.
   - 「쓸 수 없음(없는 멤버: …)」: 파일은 맞지만 필요한 기능이 없는 버전입니다.
5. 설정 창의 「저장」을 누릅니다. 이미 드라이버를 읽은 뒤에 경로를 바꾸면 「다시 시작하면 적용」으로 보입니다.
- [지우기]는 칸을 비우고 바로 저장합니다.
- 개발·시험용으로 환경 변수 `ORANDA_TIBERO_DRIVER` 에 dll 경로를 두면 설정보다 먼저 쓰입니다.

## 접속

접속 관리자에서 DBMS 를 Tibero 로 고르고 호스트·포트(기본 8629)·DB 이름을 적습니다. 드라이버가 지정되지 않으면 접속 대화 상자에 안내 띠가 나오고 [연결]·[접속 시험]은 꺼집니다.
