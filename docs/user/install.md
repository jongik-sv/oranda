# 설치

| 항목 | Windows | macOS |
|---|---|---|
| 지원 | Windows 10/11 x64 | macOS 13 이상, Apple Silicon |
| 설치 파일 | `Oranda-win-Setup.exe` | `Oranda-osx-arm64.pkg` |
| 크기 | 80 MB 이하 | 80 MB 이하 |

## 설치 순서
1. 사내 배포 위치에서 설치 파일을 받는다. 폐쇄망이면 「오프라인 설치 파일」을 쓴다. 인터넷 연결은 필요 없다.
2. Windows: `Setup.exe` 를 실행한다. macOS: `.pkg` 를 열고 안내를 따른다.
3. 처음 실행하면 접속 화면이 열린다. 다음 문서 [connect.md](connect.md) 를 본다.

## 업데이트
- 도움말 > 업데이트 확인. 사내 업데이트 서버에 새 버전이 있는지 묻는다.
- 서버에 연락하기 전에 동의 창이 뜬다. 허락한 때만 연락한다.
- 서명이 맞지 않는 패키지는 설치되지 않는다.

## 오류 보고
- 프로그램이 멈추면 오류 내용이 로그 폴더에 저장된다(도움말 > 로그 폴더 열기).
- 도움말 > 오류 보고서 에서 내용을 확인하고, 보내도 좋을 때만 「전송」을 누른다. 허락하지 않으면 아무것도 나가지 않는다.
- 접속 비밀번호 같은 값은 보고서에서 `***` 로 가려진다.
